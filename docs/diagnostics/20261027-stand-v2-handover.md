## 实际验证的方法

保留原0.2秒零电机力矩准备时间。首个可出力物理子步读取四腿当前电机角度q_start，此后在给定时长内使用：

```text
u = clip(接管后经过时间 / 过渡时长, 0, 1)
s = 3*u*u - 2*u*u*u
q_target = (1-s)*q_start + s*当前策略原本给出的合法目标角度
```

目标仍服从原关节位置限幅，原PD增益60/2、40N·m腿力矩限幅、轮速度控制及气弹簧保持。只在诊断进程中用StandV2PdAction子类，将过渡目标反算成内部腿控制动作；传给策略观测的原始动作、轮控制动作不作额外平滑。过渡结束后回到原目标映射。使用的是随当前策略变化的目标，不是冻结首个动作。

## 判断与后续边界

现有模型直接增加这套平滑过渡不合格，正式配置继续保持原控制。结果支持“接管过程与翻转密切相关”，同时说明旧策略不能直接沿用到该控制变化；不能从本次无学习对照推断重新训练一定会更好。

如继续此方向，应将候选控制过程纳入训练，再按原成功样本回归与正式行为标准验证，而非只更改回放。此次未选择正式过渡时长，未修改模型profile或导出接口，未追加训练。平滑接管也没有解决站后零速问题。
