# 轮端承重与当前XML目标高度检查

本次回应两项要求：以实际轮端接地承重解释双轮平衡；检查当前训练XML是否可达目标高度。独立原生mjlab运行环境，无PPO更新、无新训练、无历史logs改写。

## 1. 普通复位不是平衡姿态标准

用户确认保留机身近水平、不限制腿关节姿态。旧判据没有直接匹配普通初态关节角，但每轮仅要求>5 N，并只排除机身接触，没有明确排除腿连杆承重；对“主要由双轮承重”定义不完整。新版本限定轮端对地接触，按实际整机重量检查轮端与非轮负载，详见[新判据](../interfaces/chuanliantui-mjlab-v14-wheel-support-v1.md)。

原normal复位是在约0.38 m、合法随机腿姿态下释放机体，并不保证初始时双轮接地。视频的“普通初态”标签说明复位来源，不能当成期望站姿。本次未更改初始位置或强制规定腿角。

使用原3000轮recovery actor、原观测/模式/奖励，添加只观测的对地传感器，名义物理、零速度/0.30 m命令、普通/地面各64环境、20秒。新的载荷判据复核：

| 类别，末5秒 | 每轮平均支撑力 L/R | 非轮平均承重 | 机体平均高度 | 新判据持续平衡 |
|---|---|---:|---:|---:|
| 普通64份 | 67.13/64.27 N | 0 N | 0.1960 m | 64/64 |
| 地面64份，含失败样本 | 58.74/56.24 N | 16.43 N | 0.1940 m | 56/64 |
| 地面视频样本0 | 0/0 N | 131.40 N | 0.1603 m | 失败 |

整机名义重量131.40 N。普通回放末态确实由双轮承重，只是处于低位，未达0.30 m目标；地面视频样本0实际由非轮部件承担整机重量，不能从画面中轮子接近地面就认定它有支撑力。新的判据没有改变本批名义回放计数，补齐的是判定定义；不能声称旧64/64均为误判。

求解真实实体关节和闭链，不使用虚拟关节。约束两轮碰撞网格底面接地，考虑左右接地点的实际负载分配，把整机COM置于支撑线；机体只允许很小滚转以适配两侧CAD轮胎网格的微小差异。

静力方程包含实际质量、气弹簧力、闭链约束力、轮端对地反力和电机力矩，电机上限腿40 N·m、轮3.9 N·m；冗余闭链行使用独立Jacobian行空间，避免CAD坐标舍入产生虚假的侧向支撑力。

## 4. 自由平衡保持尚未通过

几何/静力可达不代表自由机体会自行保持。在以上精确初始姿态、静力补偿的60/2腿PD、真实气弹簧、无向上外力下做5秒自由机体检查：固定腿PD仍倾倒。

| 目标 | 末1秒平均高度 | 末1秒最大倾角 | 非轮平均承重 |
|---|---:|---:|---:|
| 0.27 m | 0.2562 m | 34.95° | 57.54 N |
| 0.30 m | 0.2732 m | 44.30° | 64.29 N |
| 0.34 m | 0.2883 m | 50.72° | 70.69 N |

全程有限，闭链误差最大约0.674 mm，腿力矩未饱和。另试独立诊断的轮端俯仰/速度反馈也未通过自由保持验收；这个诊断控制器没有写入训练或部署代码，不作为推荐控制器。不能用单一高度读数或本图宣称已验证自由平衡、恢复起立或策略跟踪。

当前3000轮策略的高度阶段尚未开启；上述检查证明几何和力矩能力存在，实际平衡保持仍需要控制策略，并未查明全部动态问题。没有因检查结果自行启动训练。

## 5. XML中仍需核实的建模项

- 机器人碰撞几何contype1/conaffinity0，机器人自碰撞关闭，能发生腿与机体互穿；若启用，需先为相邻安装件设置正确排除对，不能直接全开。
- 两根气弹簧滑动关节`limited=false`，没有机械行程硬限位。力曲线参考压缩90 mm不是经过实物确认的硬行程，不据此凭空写入限位。
- 主动髋XML范围约±100 rad，为宽松仿真范围；实际训练PD另外限制为CAD ref±3.14 rad。后输入轴不限圈，当前两侧膝有真实限位。XML裸范围不能直接当作硬件安全范围。

这些项需要进一步与实物机构核对，故本次没有声称XML所有物理细节均已正确，也没有改动资产破坏旧模型与姿态缓存。
