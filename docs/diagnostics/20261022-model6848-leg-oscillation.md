# 6848腿部摆动：实录与同初姿条件仿真对照

2026-10-22，按作者“对比”，复用12:21实录与已有同实测初姿条件动力学轨迹，未采新数据、未步进新仿真、未改控制/训练/物理参数。

## 结论与适用范围

**现有这段实录不支持“真机腿部摆幅比仿真大”**：首次有效出力后第2～4秒，四个腿电机角的P95−P5波动范围，实录约0.84～0.96°，仿真约8.14～9.22°；轮速前向均值反而是实录更高，约1.120对0.272rad/s。不能由此认定所有实机自由站立都摆动更小，因为绳索开始受力时刻未知，且两者起立后的平均关节角并不一致。

腿、轮和机身在闭环中互相影响，现有100Hz/50Hz保存信号不能证明哪个通道先导致振荡。启动0～1秒包含大幅起立及短暂力矩饱和，不用它代表零速站立摆幅。受拉后段不作自由站立比较。

## 第2～4秒的结果

幅度取窗口内第95百分位减第5百分位，覆盖主要波动范围，**不是最大峰峰值，也不是整条虚拟腿摆角**。四电机顺序为lf0/lf00/rf0/rf00。

| 指标 | 实录 | 条件仿真 |
|---|---:|---:|
| lf0实际角波动 | 0.918° | 8.141° |
| lf00实际角波动 | 0.897° | 8.613° |
| rf0实际角波动 | 0.841° | 9.223° |
| rf00实际角波动 | 0.956° | 9.128° |
| 四电机目标角波动范围 | 1.61～1.99° | 8.48～9.95° |
| IMU/机身俯仰角波动 | 1.065° | 2.084° |
| 统一前向双轮平均实测轮速的均值 | +1.120rad/s | +0.272rad/s |
| 统一前向双轮平均目标轮速的均值 | +3.239rad/s | +0.328rad/s |

实录四电机平均角为约`[-23.34,26.17,27.01,-23.45]°`，仿真约`[-16.91,31.09,19.67,-28.09]°`，说明仅初姿匹配不足以保证后续站姿一致。实录目标角也比仿真更平稳，不能把观察到的差异直接归因于某个电机PD参数。实录轮速存在更大的持续前向分量，但轮速不能在绳索、滑移和机身摆动未知时直接积分为真机位移。

第4～6秒亦为相同趋势：四电机实际角波动实录0.58～0.92°、仿真7.81～8.83°；前向轮速均值实录1.059、仿真0.214rad/s。它仍不是确认无绳外力的片段。
