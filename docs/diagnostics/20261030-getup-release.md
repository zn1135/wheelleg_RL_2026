2026-10-30，冻结起立前力矩罚v4千轮999模型。未改生产控制、奖励、物理或H7，没有训练。

0.2秒解除等待后直接启用默认站姿角加网络偏移的PD目标，趴地实测角与目标差48～113°，原4初态四腿首拍全±40N·m。同状态腿网络动作按零计算仍46～114N·m，默认角大误差已足以饱和；80/20只平滑网络偏移，没有平滑默认角与趴地角的差。64名义初态64/64有腿首拍满力矩、53/64四腿同时饱和。

原4初态各2秒真实500Hz对照：原策略3例0.48秒腾空失败；腿网络动作置零、保留默认PD仍3例失败。仅四腿关闭且轮电机正常或六电机关闭均0失败、0起立，最大向上速度由约0.99～1.75降至0.11～0.19m/s，支持腿部启动出力驱动蹬跳。关闭电机未失败不代表起立成功。

新增`diagnose_getup_release.py`真实子步采集与`summarize_getup_release.py`独立复算；五测量和复算退出0、Adam禁止、Actor不变，实际腿力矩与指令相同，90源码/32物理文件核对。初始qpos相同，但2号GPU等待期接触边界有约0.0106rad差，不宣称逐位同轨迹；100Hz终止可能漏过2ms短接触。仅2秒名义诊断，不替代40秒平衡/随机化验收。
