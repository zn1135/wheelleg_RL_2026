## 为什么会出现这种结果

### 1. 腿连杆撑地绕过失败终止

failure只对机身接触或roll/pitch超过40度连续20个策略步（0.4秒）及数值异常终止。腿连杆接触受undesired_contact惩罚，但不终止，也没有达到目标高度的截止时间。当前0.215m大于宽松recovered所需0.20m，所以宽松恢复指标1.0与严格恢复很低可以同时出现。平均回合1000步仅表示活到20秒。

### 2. 高度门控已经存在，但只覆盖四项速度奖励

速度门控高度误差≤3cm全额、≥6cm为0；姿态正奖励不经过高度／双轮支撑门控。末轮训练奖励项是已加权、按完整回合20秒归一化的贡献：

| 项 | 末轮贡献／秒 |
|---|---:|
| 两项水平姿态正奖励合计 | +1.9472 |
| 非轮接触惩罚 | -1.9624 |
| 高度平方惩罚 | -0.8515 |
| 高度指数正奖励 | +0.0101 |
| 线速度与偏航速度正奖励合计 | +0.0224 |
| 膝限位惩罚 | -0.0097 |

全部27项相加约-1.2071/秒，乘20秒约-24.14，与runner最终平均回报-23.43相近；两者回合汇总／平均窗口不同，不应要求数值完全相等。

9cm误差时，单个状态的高度指数奖励exp(-0.09²/0.001)≈0.000304，速度门控为0，平方高度惩罚为-0.81。正确站高仍有更高奖励，低位不是全局最优；但近目标的额外正奖励距离当前状态较远，水平低位可以持续拿姿态奖励，形成可重复的局部解。膝限位惩罚只约束关节到限位的距离，不能代表或消除腿连杆撑地。

### 3. 探索较早收缩，全部地面初态使跳出低位更难

动作std约从第0轮0.993降到第100轮0.370、第250轮0.200，末轮0.187。第500轮高度误差约7.35cm，末轮又回到8.97cm；严格恢复指标长期接近0。结合回放，这支持策略收敛到低位支撑附近的解释，不能单独证明增大探索或延长训练一定有效。关闭训练随机化也出现同样低位，故随机化不是这一现象的充分解释。100%地面初态、初始电机速度随机化和训练扰动可能增加起立探索难度，需分组实验才能量化其贡献。

## 结论和后续方向

最符合证据的解释是策略学会了腿连杆支撑的水平低位，奖励和失败条件组合允许这一局部解；未观测到该轨迹的电机饱和或数值爆炸。尚未排除站立可达性、资产几何／气弹簧参数对学习难度的影响，也没有修改模型做因果消融。

r7动态模式恢复提供阶段信息，但没有改奖励／终止，且不能修复已经训练完的r6权重。若下一轮允许调整训练参数，优先在恢复阶段增加明确起立进度，站稳后按高度与有效轮支撑门控姿态正奖励，并对持续腿连杆撑地施加分阶段约束；配合较易初态逐步增加随机化。避免在恢复动作期间直接把所有连杆短暂接地判死。单纯增加轮数不能保证摆脱当前局部解。

本次32环境/seed42评估不是跨种子成功率或H7验收；未启动新训练／TensorBoard。
