## 为什么前一组只升高约1 cm

已完成2000轮回放：普通/地面各64份、目标0.30 m、零速度、20秒、无辅助力，末5秒平均高度0.19944/0.19769 m，严格站起均0/64；数值失败0。详见 [2000轮效果](20261011-mjlab-v14-height-model1999-evaluation.md)。

本次额外诊断同一模型，名义物理、每个高度16个配对普通初态、20秒，无学习，数值失败0。目标0.27/0.30/0.34 m时，实际高度分别0.19934/0.19942/0.20001 m；高度命令仍几乎没有转化为实际抬升。

0.30 m目标下末5秒加权奖励每秒贡献：

| 项目 | 值 |
|---|---:|
| 两项姿态指数正奖励合计 | +1.98499 |
| 高度指数正奖励 | +0.00004045 |
| 高度平方惩罚 | −1.01155 |
| 电机力矩惩罚 | −0.01632 |
| 前进/偏航指数奖励 | 均0，门控已生效 |
| 终止奖励 | 0 |

最后一帧两侧被动膝距最近限位的平均距离约−0.0171/−0.0334 rad（MuJoCo软约束可存在小幅越界）；实体电机平均力矩绝对值最高约9.40 N·m，不表示瞬态最大值。低姿态通过限位附近获得支撑，力矩惩罚很小，同时仍取得姿态正奖励。这支持限位支撑的低姿态形成局部最优，不能把它当作已经成功站起。

原高度正奖励在误差10 cm时只有 `exp(-10)≈0.0000454`，远离目标的正向高度信号很弱。旧平方高度项仍有梯度，不能说“所有高度奖励都没有梯度”。续训学习率已到自适应下限1e-5，动作标准差约0.19，学习进展有限；它是待改善因素，不能单凭这个数值证明根因。

此外原V14在累计2000轮后开始30%概率的冲刺特殊采样（符合条件的回合），3000/4000轮再加入旋转。本机器人仍没学会站高，直接沿用该采样会增加任务难度。本次采用站起专项，没有修改机器人或关闭实体关节限位。

以上是代码和受控回放的诊断证据，不是逐项因果消融。首版探针误用了高度配方不存在的WEIGHTS字段，修正为其原V14权重后 `probe-v2.py` 成功；本文仅引用成功数据，首次失败日志保留远端。
