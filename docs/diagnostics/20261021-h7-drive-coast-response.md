## 连续模型与约束

对每轮，u为原记录经既有方向映射一次的名义指令，w为当前仿真轮速：

```text
v_along = max(0, sign(u) * w)
gain = G * max(0, 1 - v_along / V)^p
等效驱动 = u * gain
```

MuJoCo仍使用同一轮轴armature、阻尼和干摩擦，从实测初态按实际记录CONTROL输入自由积分。u=0时驱动为0；初态之后不读取未来实测轮速生成输入，不在300ms处拼速度、复制黑线、切换惯量或重新运行策略。加速与减速自然从当时仿真速度连续衔接，地面/机身运动仍由MuJoCo求解。

G是低速等效增益，V是同向运动时驱动趋零的速度，p决定下降形状。只作为可检验的经验候选，**不是已证明的反电动势/电压饱和/电机实际力矩模型**。改变模型增益没有改变H7电流换算；候选计算出的等效力矩可大于名义请求，不能解释成轴端实测力矩。XML仍保留原名义输入ctrlrange，候选gain只在仿真侧运行。

当指令与运动反向时，本候选暂用低速G线性缩放；该制动区域未被±3Nm悬空驱动脉冲辨识，RL小幅连续指令也属于外推。接收间隔仍不解释成控制延迟，不添加推测的延迟。

每阶段每轮100次实际MuJoCo目标函数调用、相同两个确定起点。驱动边界G=[0.25,6]、V=[30,180]rad/s、p=[0.5,4]：分别允许宽泛等效增益变化、覆盖已见约63rad/s平台、提供有限形状变化；不是硬件规格或物理置信区间。损耗边界沿用阻尼[0,.08]、干摩擦[0,2]；没有使用验证集扩界或选参。部分p到0.5下界，模型形状受边界限制，不称全局最优或已充分辨识。
