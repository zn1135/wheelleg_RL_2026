## 7. 结论分级

| 候选解释 | 结论 | 证据／边界 |
| --- | --- | --- |
| 不响应高度命令 | 已验证：工程上近乎不响应，但非数学上严格零响应 | 普通β=0.00631/0.00945；分布内共同成功β也≤约0.0101 |
| 能响应但幅度不够 | 已验证：存在很小正响应，幅度严重不足 | 命令增140 mm实际增0.90/1.41 mm；0.30 m仍低约0.10 m |
| 动作／力矩限制 | 已验证：末5s腿目标与40Nm均未触限；不足以解释稳态低位 | 三静力解目标余量≥2.872 rad、静力力矩≤7.52 Nm；全20s瞬态确有电机触限 |
| 膝关节限位 | 已验证：低位两膝限位持续参与受力；目标高位仍有余量 | 每膝16000/16000有效原生限位帧，A反力矩+11.23/−17.38Nm；目标膝余量0.20～0.423rad |
| 抬高后平衡失败 | 本次未验证；扫描中未观测到这一过程 | 0.30m命令2s后全体最高≤0.201133m，从未进入目标带；既有静力自由PD不稳不是这两个actor抬高失败的证明 |

推断：两个策略主要停留在接近膝软限位的压缩低位平衡区域，命令变化没有驱动腿目标向给定高位静力动作大幅移动；目标动作距离当前探索尺度较远。当前最直接的诊断归类是“高度响应极弱／幅度不足，伴随持续膝限位受力”，不是目标几何不可达。

未能验证：膝限位是否是形成低位策略的主因、改成高位动作是否可动态恢复并稳定、是否存在其它更近的高位动作解、训练损失和奖励的独立因果贡献、随机种子／域随机化／实物的泛化效果。没有干预动作、解除限位或改变奖励；静力解不能替代策略动态验收。
