# 双轮足恢复单因素多组对照准备

用户要求“同时测试多组”，随后回复“开始”。执行四组各4096环境、1000轮、seed=42，从同一随机网络起点训练。本记录描述实验设置，不是训练效果。使用远端RTX4090，分支 `26_wheelleg`，当前基线为r14工作区。实验入口独立于历史训练内核。

## 实验矩阵

| 组 | 唯一实验因素 | 拟用设置 |
|---|---|---|
| A baseline | 无 | 当前r14配置 |
| B wide_height | 高度正奖励宽度 | `track_height_exp_tight` 的分母0.001→0.0049，即宽度约3.16 cm→7 cm；权重仍+1，误差截断规则不变 |
| C mode_reward | normal/recover奖励调度 | recover期间四项速度跟踪奖励与静止速度惩罚不计入；normal期间沿用基线；命令观测不变 |
| D recover_timeout | recover阶段物理失败延迟 | recover期间机身接触／姿态超限的持续失败门槛由20步→250步（0.4 s→5 s）；normal仍20步；数值异常继续立即终止 |

这四组不叠加实验因素。C是奖励调度这个因素，D是恢复阶段终止延迟这个因素；不会同时增加新的正立奖励或辅助力。B仅改核宽度，不同时改高度奖励权重、目标高度或速度奖励门控。

## 共同条件

- 同一源码快照、机器人与气弹簧，r14速度／航向命令、动态模式、50%普通／50%地面初态、宽速度奖励门控和膝惩罚关闭。
- 每组4096环境、1000轮、seed=42，PPO参数相同。
- 使用随机起点，保存并核对各组首次更新前actor／critic参数、空Adam状态、学习率和初始仿真状态一致。
- 各组独立新run、控制台、退出码与配置快照；历史logs和checkpoint不覆盖。
- 先测并发显存，再并行启动；不足时明确报告资源限制，不悄悄减少每组环境数或改成串行。

## 统一评估

同一批seed和初态，分别报告普通／地面样本的严格起立成功率、首次恢复时间、站高误差、20 s物理存活率、速度／偏航跟踪误差、数值异常及轮接触。严格起立仍使用±3 cm高度误差、±15°姿态、双轮接触、机身离地连续0.5 s。D组延长训练时的失败容忍不会放宽评估成功定义；仅平均回合变长不能算起立改善。

TensorBoard命令随启动记录交付，服务不自动启动。训练启动和进度证据另见本次训练记录。未创建或切换分支，未改部署端。
