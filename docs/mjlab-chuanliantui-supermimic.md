## 已接入的流程

`python -m ct_mjlab.supermimic train` → 原任务 `task_registry.make_env` → 真实 mjlab 转移 → 回放缓冲 → 监督训练世界模型 → 想象短轨迹 → BPTT 更新 actor → lambda-return 更新 value。BPTT 是沿预测的后果反向计算动作该怎样调整；全程不创建 PPO runner，不用 PPO 的概率比值目标。

- 机器人使用唯一共享 XML，腿/轮 PD、弹簧、闭链约束、时延、随机化、奖励、终止、复位及方向课程调用原实现；100Hz策略、500Hz物理。
- 策略保持原 25维当前帧、125维五帧历史、六个原始动作及独立速度编码器。编码器仍用真实速度单独监督。网络不输入任务标志。
- 默认128环境，回放512拍，模型窗口4拍、想象8拍（80ms）、batch128；前128拍采集，先100次模型/编码器更新，再更新策略和值函数。探索叠加标准差0.2的高斯动作，不套参考机器人的±3裁剪。
- 世界模型输入125维历史、71维训练特权观测和6动作，预测下一帧、下一特权观测、实测单步奖励和物理失败。每10个环境留1个作模型验证，验证数据不参与拟合和归一化；窗口在失败和超时处截断，自动复位后的状态不作为终止转移的动力学目标。
- checkpoint独立记录算法版本、原任务契约、XML哈希、课程、三网络和四优化器。拒绝PPO/其他算法权重。续训恢复学习状态，但重新建立物理回合和回放缓冲，不声称逐拍无缝续算。

## 与参考实现的差异和当前限制

参考：RadiantForever/supermimic_wheelbipe，版本 `0bf3456299a9f754289da58dce6c97c46afd3f03`。这是 **SuperMimic范式的任务适配**，不是论文逐项复现，也不是把原机器人的权重迁过来。MLP、运行归一化及BPTT/lambda-return结构参考该MIT实现，许可在模块 `THIRD_PARTY_LICENSE.txt`。

参考实现预测物理状态，再用可微函数算奖励；本版预测观测空间状态，并学习现有任务的实测奖励/失败，不另写一套可能不等价的接触奖励。它没有可微闭链约束投影，想象状态不等于真实可实现的机器人姿态；闭链物理仅在真实mjlab中执行。

想象时使用回放中的后续命令，已知上一拍动作和固定随机化字段直接写入。停车/航向外环对新动作的反应、部分任务计时器、动作FIFO和电机响应没有显式可微重建，历史与特权观测仍只是近似状态。因此先用80ms短轨迹。即使模型拟合误差下降，也不能单凭想象回报判断策略有效，必须用真实仿真冻结评估。

验证指标 `heldout_dynamics`/`heldout_reward` 是按运行标准差归一化的均方误差；`heldout_failure` 是失败预测交叉熵。它们用于检查模型是否能预测未参与训练的环境，不等于速度跟踪误差或行为成功率。最终仍按原轮式平衡/行走验收，并与现有PPO模型在相同初态、命令和种子下对比。
