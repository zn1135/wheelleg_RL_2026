# 以轮端对地承重判定双轮平衡

2026-10-12用户要求重点检查轮端接地和受力，确认保留机身近似水平、不限制腿关节姿态。`normal`只是随机复位类别，不是期望的关节姿态或平衡标准。新配置不使用普通初态关节角来判成功。

## 判据

新增显式配方`huananhu-v14-wheel-support`，接口`chuanliantui-mjlab-v14-wheel-support-v1`，实现`ct_mjlab/experiments/huananhu_v14_wheel_support.py`和`wheel_support_goals.py`。旧recovery v1及其模型保留原意义，未改写旧训练产物。

双轮平衡须连续0.5秒满足：

- 两个轮端各有**对地接触**，传感器secondary限定为实际`terrain`几何体。
- 每轮向上支撑力≥`max(5 N, 整机重量的10%)`。
- 双轮总向上支撑力为整机重量的80%～120%，排除仅轻微触地和冲击瞬间。
- 非轮部件对地承重≤整机重量的5%，机身接触力≤1 N。
- 机身向上轴与世界竖直夹角≤15°；线速度≤0.15 m/s，角速度≤0.5 rad/s，保持原静止平衡约束。

不检查腿关节是否接近普通初态、默认角或固定的左右对称角；真实关节硬限位仍由机器人模型约束。高度是否达标继续独立检查当前命令误差≤3 cm。

重量由当前环境实际机器人body mass求和再乘9.81，包含质量随机化。名义模型13.3946 kg、重量131.4009 N，阈值对应每轮≥13.14 N、总力105.12～157.68 N、非轮承重≤6.57 N。力用当前对地净力的`clamp(-Fz,0)`，不是模长或历史峰值。

双轮奖励仍最高+2，改为按每轮相对半整机重量的承重比例计算，并要求对地接触、非轮部件不替代承重。只有少量接触力不再获得完整奖励。前两阶段高度奖励仍关闭；课程、PPO、气弹簧、控制器、初始位置和初态采样本轮均未调整。没有擅自放宽课程门槛或启动训练。
