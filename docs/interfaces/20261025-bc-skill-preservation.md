# 轮角39维BC：保留旧起立与局部平衡反馈

2026-10-25，按用户要求在旧稳定39维模型上继续学习轮角与停车。输入仍为轮角39／82／6，PD、物理、时序和H7均不改变；本记录描述训练方法，不代表新策略已经通过行为验收。当前实验结果以[项目实验记录顶部](../ai/project-log.md)为准。

## 显式初始化

`train-bc --migrate-wheel-angle --preserve-skills <manifest> --action-sampling preserve-rise-brake-stop-v1 --init <旧39BC>`是专用迁移路径。核对XML、PD源码、原39个训练／10个留出姿态成员完全相同，再复制旧actor、将第一层14、15列权重置零。其他参数和STD保留，新Adam，不恢复旧优化器。

初始动作函数等于原模型将两轮角槽置零后的函数；同为39维不表示可自动混用合同，未显式迁移的旧模型仍拒绝进入新轮角训练。新检查点格式仍为`ct_bc_actor39_pd6_wheel_angle_v1`，初始化字段记录迁移及原模型哈希，`preservation`记录保留数据和损失来源。旧PPO初始化／CPU／H7不接受该新接口，仍待适配，H7负责人核对待确认。

## 数据与三个目标

所有保留／制动数据只来自原训练侧；原40组验收初态及此前120个留出反馈状态不作为训练输入。

1. 起立保留：旧稳定actor在原39训练姿态×四种2／4ms延迟独立运行20秒，完整起立／最终平衡的轨迹提供前2秒状态。冻结旧actor在这些状态上的IEEE FP32输出作为目标；实际执行的TF32动作另存，不把两种精度结果混作逐位一致。
2. 反馈保留：从训练侧合格教师的5、7.5、10、12.5、15、17.5秒状态，构造±0.5°倾角及±0.25rad/s同向轮速的一致输入。只约束新旧actor在正负输入间的动作差值，允许停车所需的恒定动作偏置改变。这些是合成输入约束，不是扰动物理示范，也不加入SMP正示范。
3. 站稳与制动：旧稳定actor先运行10秒，LQR实际接管20秒，维持原PD/FIFO；只接收通过原平滑停车门槛的完整教师段。原正常站立教师数据同时保留。新专家采样为站立25%、制动50%、停稳25%，不再混入与旧动作竞争的教师起立目标。

主损失为上述三项缩放均方误差之和，各权重1。每次更新采样1024条专家配对、256条起立保留配对、256条反馈配对。起立尺度为保留目标训练集STD下限0.1，反馈尺度为旧正负动作差的训练集RMS下限0.01；均不读取验证集统计。网络仍输出原六路PD目标，没有新增部署缩放或结构。

保留目标与此专用训练均使用IEEE FP32。真实采集按原mjlab运行精度执行，并按完整环境批次复算动作；canonical目标另记精度差异。`BC/train_mse_scaled`记录专家项，`BC/preserve_rise_scaled`／`BC/preserve_feedback_scaled`记录保留项，`BC/total_loss`记录总损失。

## 边界和验收

这两个保留项是软约束，后续其他权重也参与训练；不能承诺更新后旧技能绝不退化。原40组起立／最终双轮平衡只要丢失一个即拒绝采用；停车与平滑另按原门槛报告。已经保存的中间模型可以零更新复测，不能据此追加优化预算。使用这40组选择检查点后，不再将其结果当作新的未见姿态泛化证明。

新增正式入口：`scripts/agent/prepare_bc_preservation.py`、`check_bc_preservation.py`、`select_preserved_bc.py`及`assess_preserved_bc_feedback.py`。数据与检查见[本轮准备](../../artifacts/bc-preserved-wheel39-20261025-v1/README.md)，实际训练／模型与验收见[实验产物](../../artifacts/bc-preserved-wheel39-train-20261025-v1/README.md)。未改H7或机器人参数，无导出／板端／真机验收。
