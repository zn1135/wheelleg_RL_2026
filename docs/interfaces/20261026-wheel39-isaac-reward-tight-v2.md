# Isaac起立奖励v2：加强站稳后的减速反馈

2026-10-26，用户认可Isaac奖励200轮模型的整体观感，要求基于它优化奖励。本轮只修改、检查，不训练；model_199保留为后续优化起点，不覆盖原文件。此前末段漂移指标不变，不将用户认可写成停车验收通过。

## 改动及依据

当前模型末5秒平均速度0.022117m/s，前向绝对速度0.022059m/s、侧向0.001085m/s。原速度两项在该轨迹的合计加权奖励为0.1995475，完全静止为0.2，仅差0.0004525；慢漂几乎不损失速度奖励。这个数值是已录轨迹重算，不是完整失败原因归因。

新配置 `--bc-finetune isaac-standup-v2` 在 `smp/isaac_standup_rewards.py` 中的 `velocity_scores` 和 `TIGHT_WEIGHTS` 定义，只改两个线速度奖励：

| 项目 | 原Isaac奖励v1 | 新v2 |
|---|---|---|
| 速度平方误差 | (vx-command_vx)² | (vx-command_vx)²+vy² |
| 主项指数分母 | 0.25，即0.5m/s的平方 | 0.0004，即0.02m/s的平方 |
| 主项权重 | 0.2 | 1 |
| 增强项指数分母 | 2.5 | 0.04，即0.2m/s的平方 |
| 增强项权重／公式 | 0.2×(exp(-error/sigma)-1) | 保持，采用上行新sigma |

两项仍由原奖励的`has_stood`门控：曾连续0.5秒达到目标高度下2cm、重力z≤-0.9、机身接触力≤0.1N且已轮触地之后启用。起立前两项为0，不惩罚必要的起立运动。宽尺度增强项保留较大速度误差的减速反馈，主项针对慢漂。0.02m/s是奖励宽度，不是放宽停车验收门槛。

其余17项、高度命令0.33648m、SMP权重1、初态、39／82维观测、0.2秒出力等待、2ms物理／100Hz策略、2／4ms动作延迟、原轮角参考以及机器人XML保持。仍没有0.22m课程，也未加绝对位置锚点。

同一批已录末段速度（按已站稳重算），新两项合计0.3125953，静止为1，差0.6874047。速度0／0.005／0.01／0.02／0.05／0.1m/s时，新合计分别为1／0.9393／0.7783／0.3659／-0.0102／-0.0442。这里是奖励辨别能力，不证明PPO已经减速。
