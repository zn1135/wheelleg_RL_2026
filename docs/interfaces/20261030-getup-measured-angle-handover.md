## 执行定义

保留[80/20四腿动作平滑](20261030-getup-leg-action-smoothing.md)，新增0.1秒位置目标接管。旧标识为`split-getup-leg-ema80-policy100hz-hold-reset-v2`；新`action_filter_contract`为`split-getup-leg-ema80-handover100ms-physics500hz-v3`。权威源码为`chuanliantui_split/action.py::GetupPdAction`、`runner.py::contracts`及共享`chuanliantui/huananhu_action.py::_leg_position_target`；共享方法仅抽出原目标角计算，其他动作类返回值不变。

地面起立的0.2秒零力矩等待结束后，在首次可出力的2ms物理子步锁存四实体腿电机实测角`q_start`。先按原延迟队列、默认角加0.5倍动作及原位置限幅得到当前网络目标`q_policy`，再在PD之前计算：

```text
u = clip(自首次可出力子步起经过的时间 / 0.1秒, 0, 1)
s = u² × (3 − 2u)
q_target = q_start + s × (q_policy − q_start)
```

每2ms更新一次接管比例，0ms恰为实测角，100ms及以后使用完整当前网络目标。`q_policy`仍随100Hz网络动作及原延迟变化；不是锁住首个网络目标。接管在延迟之后，不再额外延迟过渡过程。首次仅位置误差为零，原速度阻尼仍可能出力，不能称首次电机力矩必为零。局部复位只清该环境的滤波、起始角、开始标志和物理步计时；新回合重新读取实测角。非地面初态不启用此过渡。

轮子、原始动作观测、25/125/71/6形状、PD增益/限矩、物理模型/弹簧、目标高度/课程、奖励及终止条件均保持。walk和独立stand_v2不启用此过渡。目标角插值不是力矩上限调低，后续仍可达到40N·m。
