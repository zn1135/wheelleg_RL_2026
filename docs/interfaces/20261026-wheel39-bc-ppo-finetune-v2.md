# 轮角39 BC→PPO微调v2：释放动作改进幅度

2026-10-26，用户目标“训练出超过LQR的PPO”，允许自主配置。旧版100及400轮均保留起立／平衡／平滑40/40，停车0/40；相同末段BC观测上的腿目标变化仅约0.000018rad。原生LQR同10个姿态停车4/10且更平滑。证据见[累计400轮报告](../../artifacts/ppo-bc-finetune400-20261026-v1/README.md)。

## 与v1的区别

新实验标识`chuanliantui-smp-ppo-wheel39-bc-finetune-v2`。actor39／critic82／动作6，原轮角清零合同、XML、标定、2ms物理／PD、100Hz策略、0.2秒门控、正常趴地初态、零速命令和2／4ms动作延迟均保持。

| 训练项 | v1 | v2 |
|---|---|---|
| 探索动作标准差 | 腿0.001／轮0.005 | 相同，固定 |
| BC偏离损失的归一化尺度 | 直接用上述标准差 | 单独用腿动作0.05／轮0.1 |
| 减速奖励速度尺度 | 0.05m/s | 0.01m/s |
| BC参考／损失系数 | 冻结原BC，系数1 | 相同 |
| 价值预热／学习率／KL | 20轮；动作1e-6、价值1e-4；KL0.01 | 相同 |

v2将BC约束中的腿二次项系数降低2500倍、轮降低400倍，保留小探索噪声；不是增大随机动作。容许尺度以原始六路策略动作计，腿0.05对应PD目标角0.025rad，轮0.1对应目标轮速1rad/s；这些是软损失尺度，不是硬动作限幅。减速奖励仍权重2，位置权重1，锚点与其他奖励保持。

候选修正针对动作被锁得过近及慢漂奖励较平的问题，尚未证明可以停车或超过LQR。两处一起变化，不能把新效果单独归因某一项。

## 实现与兼容

`smp/finetune.py`保留v1原配方，新增`ProtectedPPOV2`及独立检查点recipe；共用PPO更新实现，但按实例recipe选择动作偏离尺度。`train --bc-finetune`仍默认v1；`--bc-finetune v2`选择新版。play／eval／check及无显式variant的resume从检查点恢复v1或v2；跨recipe／profile恢复拒绝。

v2从原稳定BC重新初始化actor、价值网络与优化器从新开始，先运行200轮，前20轮价值预热包含在内；不直接续训v1的400轮模型，不覆盖旧实验。不改变PPO物理初态分布。

## 验证与边界

`check_ppo_bc_finetune.py --variant v2`检查新损失方向、价值预热／动作梯度、参数不变、检查点恢复和40组真实采样20秒，优化器写入全部拦截；随后正式产物复算通过。零更新起立／平衡／平滑均40/40、停车0/40；不能当训练效果。

`check_wheel39_ppo_entries.py --bc-finetune v2`在learn前拦截，核对真实初始化／恢复、play／eval／check各有限4步，未启动可视服务。旧v1最终model_399通过有限回放，默认v1含义保持。证据见[检查目录](../../artifacts/ppo-bc-finetune-v2-check-20261026/result.json)及其`assessment.json`、`entries/check.json`、`legacy-check.log`。

待训练后复测原40组、逐物理步平滑与原生LQR对照并保存视频；仍须额外检验不同初态、完整随机化、10ms和真机泛化。没有H7或硬件交付，负责人核对待确认；不改物理参数来适配策略。
