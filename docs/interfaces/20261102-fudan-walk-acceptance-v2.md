## 采样、测量段与时间边界

每个tick为2ms。有效完整轨迹有`duration/0.002+1`个状态采样。区间统一左闭右开`[lo_tick,hi_tick)`；最后一项是回合终点状态，保留峰值/倾角诊断和异常标记，但不算作多出来的2ms力持续时间。缺字段、缺点、错时间网格、无穷或NaN、无有效窗口均拒绝，不能缩小分母。时间网格只允许1e−7秒存储误差，选择窗口使用整数索引。

- 轮载正式测量段：每个恒定命令段的`[段起点+2s,段终点)`；刹停的行驶段相同，停车则用原算法找到的最早停稳完成点开始，观察5s。变高各段仍先响应2s。每段单独检验，不能用其他段的好结果抵消。
- 20ms滑动均值：连续10个原始样本，每2ms移一步；只保留完全落在该段内的窗口，不补零，不跨段。N个原始样本产生N−9个有效窗口；例如5s测量段2500点产生2491窗。
- 一段连续异常有K个相邻的窗口起点时，持续时间记`K×2ms`，不把重叠窗口覆盖的原始数据跨度误当异常时长。原始失载/接触的连续时长同样是连续异常采样数乘2ms。

## v2技术门槛

| 项目 | 判定 |
|---|---|
| 平滑轮载 | 在每个正式测量段，10点平均后的每轮支撑≥`max(.1×平均mg,5N)`，两轮合计在`[.8×平均mg,1.2×平均mg]`；三条件同时满足的窗口比例≥95%，且连续不满足必须短于100ms。恰好95%允许；恰好100ms失败。 |
| 原始双轮同时低支撑 | 同一正式测量段，每2ms原始记录中两轮都<1N，连续达到20ms即失败；恰好20ms失败。不能用均值掩盖。复位最初离地间隙不在该正式测量段内。低支撑不自动解释为几何离地。 |
| 起步短接触 | 仅回合`[0,2s)`内，对机身力>10N的采样计时：单次≤20ms且累计≤50ms。等于这两个上限允许；原始峰值/每次区间均记录。 |
| 正常阶段机身接触 | 全回合`[2s,回合终点)`内任一完整20ms窗口的机身力均值>1N即失败，等于1N允许。窗口不混入2s以前的采样，也不在每次命令改变后重开起步宽限；包括后续转向、变高和停车过渡。 |
| 速度、转向、高度、俯仰、停车 | 完整沿用v1公式和门槛：速度/yaw MAE≤.20、至少95%误差≤.30；高度MAE≤.03m、至少95%误差≤.05m；测量段max\|pitch\|≤10°；停车3s内完成1s连续低速并再观察5s，每拍水平速度≤.1m/s，不新增漂移门槛。 |
| 姿态/异常 | 全轨迹max(\|roll\|,\|pitch\|)>60°、数值异常或提前终止仍失败。末1s原有tilt≤35°和roll/pitch角速度合量≤.5rad/s继续保留，yaw不计入该合量。 |

v1的“任意机身力>10N即fell”和“末1s每拍轮载都达标/机身力≤1N”只保留在`v1_diagnostic`，不得再次作为v2隐式否决。`fell`原本合并了接触与大角度倾覆，不能把这个旧字段直接翻译为“摔倒”。
