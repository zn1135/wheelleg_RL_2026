用户提供的2026-11-03 USB时序摘要报告1500次策略/30秒，与50Hz软件口径相符。但原始run03、预期固件清单和实际板上版本证据尚未交至本次审查，不能据此证明板上恰为本PR提交，更不能将0.725ms SDK耗时当作复旦8000轮模型的实测值。
