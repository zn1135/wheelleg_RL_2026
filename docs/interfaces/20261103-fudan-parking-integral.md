# 8000轮停车积分诊断

用户明确授权固定方案、唯一600秒窗口，回放最迟360秒结束，无训练/调参/重试追加。使用8000-v2冻结模型及20261102三档GPU各15名义工况，不更改H7、原奖励、网络、Actor估速、PD、物理或ONNX。

实现为独立`parking_integral.py`，所有参数集中于`FudanWalkCfg.parking_integral`，默认关闭，不接入普通训练/导出，也不增加功能命令行开关。试验入口内部固定基线、真值积分、Encoder积分三分支。每高度将三个原15工况并排成45环境，直接恢复归档qpos/qvel、PD中心/增益/强度及五类物理数组，禁止重新随机生成或重求闭链姿态。三高度135个运行时初态全部核对后才开始策略回放；目标是保存135条轨迹。各分支单独复制原归档文件，不共用同名输出。qpos按归档转运行时精度后加环境原点作世界坐标逐值比较，其余数组按运行时精度逐值比较，不增加容差。不一致时先保存实际/期望/逐分量差值NPZ、不同索引及最大绝对差JSON，再停止。GPU批量布局的数值差异须经基线复现门槛检验，不能直接假定复现。

顺序：每拍以原始vx/yaw检查门控，用已有积分产生当前vx补偿；只写当前观测6:9和历史末帧对应槽；原Actor推理一次并执行原环境10ms步（历史只推进一次）；在步后t+.01读取本次训练口径10ms位置差分机体系vx，同时只对新历史额外调用一次Encoder取反馈并除以2，再更新积分供下一拍使用。Actor推理时刻t、反馈采样和积分提交时刻t+.01分别记录；每拍Actor一次、Encoder两次（Actor内部一次、反馈一次），第二次不调用Actor、不采噪声、不修改历史。Actor始终使用原Encoder输出，真值仅流入独立积分。启动真值差分为0，门控前不积累。积分无固定世界停车点，不含扰动返回原点功能。

接触以真实2ms样本维护10样本/20ms滚动均值，t=0只放1样本，不复制填满；完整接触窗口形成后首个合格检查计时为0，连续50个10ms间隔后启用，首次激活补偿为0，首个反馈在该拍结束后提交。原始vx/yaw非零、|roll|或|pitch|≥10°、任一轮均力≤1N或机身均力>1N即清零；步后再检查一次，失效不留积分到下拍。局部reset清对应环境积分/计时/接触窗口，其余环境不受影响。无自动复位替代失败。非有限输入抛出异常，终止回放并保存已有轨迹。

正式入口（本次动态预算启动后不得再复用输出目录）：

```bash
PYTHONPATH=mjlab_training/src mjlab_training/.venv/bin/python -m scripts.agent.fudan_ppo_walk.check_parking_integral --output <新目录>/checks.json
PYTHONPATH=mjlab_training/src mjlab_training/.venv/bin/python -m scripts.agent.fudan_ppo_walk.run_parking_integral --output <同目录>
```

无物理检查使用真实v2槽位/step和非物理夹具，禁止MuJoCo积分、真实环境步、NN层前向及Adam；动作恒等检查用确定性代数探针，未在预算外启动冻结模型。动态阶段的原Actor代码/权重和命令旁路保持另有源/模型哈希、初态及基线复现校验。修复检查增加135个归档初态的替代后端恢复、一个最小浮点差的拒绝及证据文件、故意不同的步前/步后反馈、Actor/Encoder调用顺序和无轨迹失败报告。替代后端通过不代表GPU运行时初态或行为通过。无轨迹时报告从实际初始化结果/日志读取错误，分别统计一致、不一致和未核对数量，跳过视频生成。

流水线在首个模型/仿真子进程之前启动单一单调时钟，OS等待超时会杀死整个子进程组（含编码器）：回放360秒硬停，345秒软停预留保存；全部计算600秒硬停，视频592秒软停。预算包括子进程导入、模型/后端初始化、采集、评分、视频和解码。缺失仍留原135条分母，无重跑、补时或新预算。源码/旧输入/模型哈希核对及完成清单仅为整理已有结果。

评分严格用原始协议命令：保存各分支45例共用统一报告，任一原成功样本丢失为退化。另固定原地2～7秒、前后停车10～15秒，速度用500Hz世界XY速度模长均值/峰值（左闭右开），最大偏移包含窗口终点。基线九停车例5秒净位移与原8000记录差≤2cm，且核对XY矢量差；不满足禁止改善结论。候选九例各自最大水平偏移≤5cm、均速≤.01m/s、峰速≤.05m/s且45例不退化才称数值有效；真值独过时只能称受估速反馈限制，最终仍待用户完整视频确认。

饱和、门控原因、退出残留和实际覆盖写入比较JSON。合成检查通过不代表动态退出已覆盖；本协议没有另加退出/推扰工况，未发生的条件明确未验证。每高度正常1倍速并排37秒视频，保留原地7秒、后退停车15秒、前进停车15秒，失败不删。三分支每帧展示组别、原始/实际指令和时间。
