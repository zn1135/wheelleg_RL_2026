# 双轮平衡配对验收（当前 v3；保留历史 v2）

## 当前标准：最终双轮平衡 v3（2026-10-16）

按用户“只要最后能保持平衡”的要求，multimode 中途击倒验收改为：**预定回合结束前连续 1 秒满足下表全部条件**。允许正常滚动，恢复过程中晃动不直接判失败；不再要求末 5 秒有 95% 时间达标。

**当前实现版本 v3.1**：核对用户指出的 env198/311 后，排除转向速度对失衡判定的影响，允许双轮主要承重时有少量腿部接触。此前 v3 使用三轴角速度和非轮支撑≤5%，其5/7重算结果保留为历史，不能作为本版本结论。

| 条件 | 门槛 |
|---|---|
| 每轮对地向上支撑 | ≥整机重量10%，且≥5 N（正支撑同时保证双轮接触） |
| 双轮合计支撑 | 整机重量80%～120% |
| 腿部少量接触 | 不单独否决；双轮仍须承担至少整机重量80%，机身不得撑地 |
| 机身接触力 | ≤1 N |
| 机身倾角 | ≤35°（沿用 max(横滚角绝对值, 俯仰角绝对值)） |
| 横滚／俯仰角速度合量 | ≤0.5 rad/s，仅检查左右与前后翻转；绕竖直轴转向不否决 |
| 根节点线速度／高度／起身用时 | 不作为最终平衡成功门槛 |
| 观察完整性与数值 | 必须观察至预定结束时刻且无数值异常；提前物理终止不通过 |

`scripts/agent/assess_multimode_knockdown_recovery.py` 输出 `final_balanced`（当前成功标记）和 `final_balance_hold_s`（结束前连续合格时长，任意一拍不合格即清零）。击倒前的站立不计入；未送达冲量的回合单列，不能计为恢复成功。统计仍以冲量后确实倒地的样本为分母，未倒地的抗扰表现单列。

`last5_pure_v2_fraction`、`last5_v2_fraction`、`recovered` 保留原定义作为历史指标，不再否决当前最终平衡。旧产物没有逐步轨迹时不能从末 5 秒占比推算最终连续时长。`compare_multimode_knockdown.py` 默认比较 `final_balanced`，缺少该字段会拒绝；显式 `--criterion legacy-v2` 才按旧口径复查。两边必须使用相同判据与物理／初态协议，原成功样本任一失效的退化否决规则保留；旧“曾恢复”不再独立否决 v3。

只修改测量与验收，不改变训练奖励、终止规则、恢复窗口、策略、观测或 H7 接口。历史 v2 数字保持原义，不能直接重标为 v3；模型仍须用新口径重新配对验收。

## 个体平衡

零速度命令回放必须同时满足下列条件，末5秒至少95%的控制步满足才记为持续平衡。曾连续0.5秒成功仅表示曾经恢复，不能替代最终稳定平衡。

| 条件 | 门槛 |
|---|---|
| 轮端接触 | 两个轮端都与地面实际接触 |
| 每轮对地向上支撑 | ≥整机重量10%，且≥5 N |
| 双轮合计支撑 | 整机重量80%～120% |
| 非轮部件对地支撑 | ≤整机重量5% |
| 机身接触力 | ≤1 N |
| 机身倾角 | ≤15° |
| 根节点线速度模长 | ≤0.15 m/s |
| 根节点角速度模长 | ≤0.5 rad/s |
| 数值 | 全程无数值异常，物理量有限 |

按实际质量计算重量。当前名义重量约131.4 N，每轮至少约13.1 N，合计约105.1～157.7 N，非轮支撑最多约6.6 N。

不约束腿关节角，也不使用普通复位角判定。高度跟踪另要求目标±3 cm；低位双轮平衡不代表高度目标达标。

## 三类结果分开报告

1. **轮端承重**：只检查地面接触与承重分配；承重但旋转/移动不能算静止平衡。
2. **稳定双轮平衡**：承重、近水平、无机身支撑及静止条件同时成立。
3. **高度跟踪**：稳定双轮平衡基础上达到高度命令。

评估逐样本记录末5秒各条件成立比例、组合条件结果、轮端与非轮平均支撑、失败条件。各条件单独平均达标仍不能代替组合条件同时达标。失败原因可重叠，不把整批平均力当成每个样本的证据。

## 模型退化否决

与2000轮源模型在相同初态、命令、物理和20秒协议下配对比较，普通和地面分别比较成功样本集合。

- 原成功样本有任何一个失效：`regressed_rejected`，明确标记**退化，验收不通过**。
- 新增成功样本不能抵消丢失，包括总成功数相同或上升的情况。
- 数值失败同样不通过。
- 无丢失且无数值失败仅表示**保留原平衡能力**；全部初态平衡、全部高度达标分别报告，不能据此声称部署合格。
- 初态指纹、评估协议或成功样本计数不一致则拒绝配对。

E组`keep_contact`的56/64是统计值，不能作为组级合格判定。它丢失原成功地面样本0、55，因此明确退化。样本0轮端支撑约0/0 N、非轮支撑约131.4 N，属于非轮撑地失败。
