# 双轮平衡配对验收 v2

2026-10-12按用户对E组明显退化的纠正，新增独立回放验收标准`wheel-balance-paired-acceptance-v2`。

## 个体平衡

零速度命令回放必须同时满足下列条件，末5秒至少95%的控制步满足才记为持续平衡。曾连续0.5秒成功仅表示曾经恢复，不能替代最终稳定平衡。

| 条件 | 门槛 |
|---|---|
| 轮端接触 | 两个轮端都与地面实际接触 |
| 每轮对地向上支撑 | ≥整机重量10%，且≥5 N |
| 双轮合计支撑 | 整机重量80%～120% |
| 非轮部件对地支撑 | ≤整机重量5% |
| 机身接触力 | ≤1 N |
| 机身倾角 | ≤15° |
| 根节点线速度模长 | ≤0.15 m/s |
| 根节点角速度模长 | ≤0.5 rad/s |
| 数值 | 全程无数值异常，物理量有限 |

按实际质量计算重量。当前名义重量约131.4 N，每轮至少约13.1 N，合计约105.1～157.7 N，非轮支撑最多约6.6 N。

不约束腿关节角，也不使用普通复位角判定。高度跟踪另要求目标±3 cm；低位双轮平衡不代表高度目标达标。

## 三类结果分开报告

1. **轮端承重**：只检查地面接触与承重分配；承重但旋转/移动不能算静止平衡。
2. **稳定双轮平衡**：承重、近水平、无机身支撑及静止条件同时成立。
3. **高度跟踪**：稳定双轮平衡基础上达到高度命令。

评估逐样本记录末5秒各条件成立比例、组合条件结果、轮端与非轮平均支撑、失败条件。各条件单独平均达标仍不能代替组合条件同时达标。失败原因可重叠，不把整批平均力当成每个样本的证据。

## 模型退化否决

与2000轮源模型在相同初态、命令、物理和20秒协议下配对比较，普通和地面分别比较成功样本集合。

- 原成功样本有任何一个失效：`regressed_rejected`，明确标记**退化，验收不通过**。
- 新增成功样本不能抵消丢失，包括总成功数相同或上升的情况。
- 数值失败同样不通过。
- 无丢失且无数值失败仅表示**保留原平衡能力**；全部初态平衡、全部高度达标分别报告，不能据此声称部署合格。
- 初态指纹、评估协议或成功样本计数不一致则拒绝配对。

E组`keep_contact`的56/64是统计值，不能作为组级合格判定。它丢失原成功地面样本0、55，因此明确退化。样本0轮端支撑约0/0 N、非轮支撑约131.4 N，属于非轮撑地失败。
