## 新增输入和时间顺序

下列索引从0开始。原actor 0～38和critic 0～81字段、缩放、动作映射均不变；机体前向+x，命令仍为偏航角速度。

| 输入 | actor／critic索引 | 来源、单位、复位 |
|---|---|---|
| 通用轮式里程 | 39／82 | `.03 × (左轮累计角差−右轮累计角差)`，米、缩放1、不回绕；0.06m轮半径。只在回合复位记录编码器起点，不随起立、制动或换命令清零 |
| 共享参考位置误差 | 40／83 | 教师原LQR的`target[:,0] - x[:,0]`，米、缩放1；沿用H7估计器的轮／腿／俯仰补偿和融合速度误差积分，积分限幅±3.5m，不等于通用轮式里程 |

参考估计器每10ms在观测前更新一次。同一拍actor、critic、教师目标共用缓存；同拍重读不推进积分。部分环境复位仅重建该环境的历史。估计器读取与教师相同的传感器反馈，独立学生回放也实时计算这项输入；计算出的教师力矩不写入PD或仿真控制。

原H7正常起立交接、离地状态变化及回合复位沿用原清零规则。每回合首次实际连续双轮支撑满1秒时，只在旁路估计器尚未进入DONE的情况下同步阶段并锁定当前位置／朝向；正常教师已进入DONE时不额外重锁。实际教师接管纠偏另在10秒、持续支撑满1秒时显式重锁，事件和重锁前后状态逐拍记录。通用里程独立保留回合原点。

观测／目标对应动作执行前的同一状态，`observation_time = action_time = time - 0.01`。日志保存`reference_error`、积分前后值、积分速度误差、使能、前后清零标记和事件位，检查脚本可独立重算递推。既有历史文件缺失这些状态，重新采集，不用事后轮位移冒充教师参考。
