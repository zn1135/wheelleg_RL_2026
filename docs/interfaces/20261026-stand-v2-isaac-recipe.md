## 接口定义与差异

| 项目 | 原mjlab稳站 | v2 |
|---|---|---|
| 观测 | Actor39/Critic82，固定缩放、轮角占位 | 索引/缩放不变；噪声改为Isaac幅度，轮角占位不加源中不存在的噪声 |
| 历史、前向、yaw | 无历史编码器，+X前向，yaw角速度 | 不变 |
| 关节与动作 | 六实体电机，腿0.5rad/轮10rad/s，PD60/2 | 顺序、参考基准、控制和限幅不变；名义角随机偏置改为±0.03rad |
| 时序 | 500Hz物理/100Hz策略；动作每回合腿轮独立10/20ms | 频率不变；动作域随机化改为启动时0～10ms取整、腿轮共用；观测时延不变 |
| 初态与控制接管 | 50%近站/50%地面，地面前0.2秒零电机力矩 | 100%地面姿态库；0.2秒零电机力矩不变，不引入源PPO首次接地屏蔽 |
| 命令与课程 | 固定0.27m、外扰分阶段 | 源0.30→0.22m高度课程，4096回合窗口成功率≥30%永久解锁；零速不变 |
| 停止条件 | 连续倒地2秒、45m边界及原数值阈值 | 源倒置/双轮离地0.2秒/曾站起后倒地超过1秒，另保留非有限状态终止；40秒回合长度不变，首次接地另计时 |
| 物理资产 | 共享XML、压缩相关气弹簧、轮端响应 | XML不改；采用Isaac域随机化适配，恢复系数为MuJoCo近似；气弹簧保留名义曲线/阻尼、关闭额外随机项 |
| 模型格式 | 完整PPO checkpoint | 不变，新增独立profile和课程状态；本轮没有训练或导出模型 |
