# 扶正、双轮平衡与高度跟踪的独立配置

2026-10-12，用户确认目标为“两者都要，最终跟踪高度命令”。本配置修正此前把站起统一等同于达到固定0.30 m的理解。只准备配置与检查，本次不启动训练。

## 目标与成功判据

| 指标 | 条件，均须连续0.5秒 | 是否要求达到高度命令 |
|---|---|---|
| `righting_success` 扶正 | 有限状态，机体向上轴与世界竖直夹角≤15° | 否；允许身体仍接触地面 |
| `wheel_balance_success` 双轮平衡 | 扶正、两轮向上支撑力各>5 N、机体接触≤1 N、根节点线速度模长≤0.15 m/s、角速度模长≤0.5 rad/s | 否 |
| `height_tracking_success` 高度跟踪 | 双轮平衡，机体根节点相对地面高度与当前命令误差≤3 cm | 是；不是固定0.30 m |

双轮平衡成功还不能替代最终高度跟踪成功。恢复后允许腿在低位保持平衡；之后必须根据高度命令伸展或收缩。此处高度仍是本仓的机体根节点高度，不是轮心到髋关节的腿长。

观测维数35/78、四腿在前两轮在后的动作与关节顺序不变。恢复标志采用动态normal/recover；连续0.5秒双轮平衡后退出recover，独立于高度误差。高度命令仍通过原高度观测槽提供给策略，恢复模式槽保留目标高度和状态时间。

## 整批课程

顺序为 `righting → wheel_balance → height_tracking`，不按单个环境切换奖励阶段。前两次推进须整批至少2/3环境满足当前阶段即时判据、连续2秒，并且本阶段至少经过2400个控制步（100次PPO更新）。课程状态和历史保存到checkpoint，正常续训恢复；从已知2000轮旧模型显式迁移时，课程从扶正重新开始，累计训练轮数保留。

三阶段均为零前进/偏航速度命令；高度命令按原5～15秒周期在0.27～0.34 m均匀采样。扶正和平衡阶段关闭高度奖励，最后阶段才启用。此配置专门解决恢复与高度跟踪；行走仍使用各自历史配置，未自动加入第四阶段。

## 与2000轮高度门控组的变化

| 项目 | 新配置 |
|---|---|
| 初态、机器人、PD、闭链、气弹簧、动作延迟、物理步长、随机化 | 保留；普通50%/地面50%，地面机体零姿态 |
| PPO | 保留V14自适应学习率；迁移恢复Adam及其学习率，不使用失败3000轮组的固定5e-5 |
| 姿态奖励 | 原xy重力项补入倒置项；指数项乘`clamp((1-gz)/2,0,1)`，平方项各加`0.5*(gz+1)^2`，原权重不变；防止完全倒置取得与正立相同姿态分数 |
| 双轮支撑奖励 | 平衡与高度阶段增加权重+2：`min(clamp(轮支撑力/5,0,1))*clamp((1-gz)/2,0,1)` |
| 高度奖励 | 前两阶段为0；最后在扶正、双轮支撑且机体离地时，`exp(-abs(error)/0.12)`权重+1，`(10*error)^2`权重−1 |
| 速度跟踪四项 | 专项任务均关闭；静止速度惩罚、动作平滑、关节速度/加速度、功率等原V14项保留 |
| 非期望接触惩罚 | 扶正阶段关闭，平衡与高度阶段恢复原权重 |
| 终止 | 有限触地/倾斜不再0.4秒终止，允许20秒恢复；数值异常立即终止；到20秒当前阶段仍未连续成功0.5秒，判失败 |
| 辅助力、被动膝限位、默认角惩罚 | 均关闭 |

轮向上支撑力严格用`clamp(-primary_to_secondary_Fz,0)`；不使用力的绝对值、模长或历史最大值。成功计数、课程门槛和独立评估复用同一组判据。训练终止奖励权重仍为−200；mjlab RewardManager乘控制步长0.02秒，因此单次失败贡献为−4，而不是额外一次不乘步长的−200。

## 原生检查与独立评估

在独立Linux mjlab环境中运行，不使用Windows系统Python，也不更新策略：

```bash
PYTHONPATH=mjlab_training/src "$MJLAB_PYTHON" scripts/agent/check_chuanliantui_recovery_height.py \
  --checkpoint /absolute/path/to/height-group/model_1999.pt --output /new/check-directory

PYTHONPATH=mjlab_training/src "$MJLAB_PYTHON" scripts/agent/eval_chuanliantui_recovery_height.py \
  --checkpoint /absolute/path/to/model.pt --output /new/eval-directory \
  --num-envs 64 --height 0.30
```

评估分开输出扶正、双轮平衡、高度跟踪的成功数量及末5秒持续成功数量，普通/地面各一批。通过`--height`分别检查0.27/0.30/0.34 m；只有完成多高度回放后，才能声称策略跟踪了高度命令。旧评估的`strict_recovered=0`只能说明它没有通过旧的“高度±3cm+姿态+双轮接触”组合判据，不能据此单独断言它完全没有扶正。

检查结果和行为复核见 [本次验证](../diagnostics/20261012-mjlab-recovery-height-check.md)。有限状态检查和无学习迁移通过，不等于新奖励已经学出合格行为。
