## 命令、门控与斜率

新配方须同时显式开启`post_stand_tracking=True`及`speed_curriculum=True`。默认零速与旧0.1～0.3m/s跟踪入口保持。100%原地面初态，每回合仍独立50%概率选择跟踪角色；另50%整回合零速。不是一半环境站立初始化，也不强制有限批次恰好半数。

`has_stood && NORMAL && !fallen`额外连续50策略拍（0.5秒）才允许跟踪。未就绪或失稳当拍立即把实际vx、隐藏目标、转换计时清零；恢复后重计0.5秒。安全清零优先于限斜率，不能算正常斜率违规。局部复位只改变对应环境，重复读取不推进时间。yaw始终0。

每回合独立采样`a ~ Uniform(0.5,2.0)m/s²`，配置项为`tracking_acceleration_range`。100Hz命令更新：

```text
u_next = u + clamp(target - u, -a*0.01, a*0.01)
```

Actor、历史、Critic、奖励全部使用实际下发的`u`，不使用隐藏目标。主跟踪有效权重在`u != 0`时仍1.0，否则0.2，指数分母仍0.25；其余奖励逐项不改。急停目标是0，观测先按斜率减到0；失稳是立即清零，两者不同。

命令有效期间每200～400拍（2～4秒）重采样一次隐藏目标／转换。已有非零目标时，急停25%、换向25%、保持50%；已有零目标时，急走75%、保持零速25%。急走的幅值均匀采样0.1～本档上限，正负等概率；换向取旧目标相反数；保持不改变目标。概率按当前状态条件化，保证不会把0→0标成换向。即便斜率未完成也允许下次重采样，模拟快速遥控变化。跟踪回合可以有零目标段，整回合零速角色仍占50%。

## 速度课程与checkpoint

上限分0.5→1.0→1.5m/s三级；3999迁移从第0级开始，yaw不扩展。晋级采用至少256个**目标幅值≥本档上限80%的非零命令段**组成窗口，其中至少80%成功才升级；不按训练轮数自动晋级。成功要求命令斜率完成后等待0.5秒、至少累计测量0.5秒，机体系vx对实际命令的平均绝对误差≤0.30m/s，且该段未失稳。测量不够或失稳仍计该段失败，不能只统计存活成功者。窗口不足256不晋级，失败窗口清零重计；顶档不再升。晋级前开始的旧档段不混入新档窗口。

配置项：`speed_limits`、`speed_error_threshold`、`speed_promotion_segments`、`speed_promotion_fraction`，默认分别为(.5,1.,1.5)、.30、256、.8。短命令段与低斜率可能使稳定测量不足，从而保守地延迟晋级；1000轮不保证解锁到1.5。

`infos.standup_curriculum.speed_curriculum`保存stage、窗口segments/successes、最近成功率及完整命令配置，完整续载恢复；配置不匹配在加载权重前拒绝。物理环境仍重新复位，未完成的单环境段不跨物理重启拼接。40秒打散复位预运行不更新晋级统计；只检查／play／验收也冻结晋级。

从3999迁移时先按v5完整恢复Actor/Critic、PPO和编码器两个优化器及起立课程，再显式打开新命令版本；旧模型文件不改。后续v6模型须显式指定新开关，普通v5或零速入口拒载，不能仅靠维度相同混用。

## 独立速度验收

`scripts/agent/assess_stand_v2_speed_transients.py`：128环境默认前64例零速，后64例均分±0.5/±1.0/±1.5m/s；全部从地面起立。固定8秒起立，8～14秒急走、14～18秒保持、18～24秒急停、24～30秒再急走、30～36秒换向、36～40秒急停；保留生产门控和限斜率，用外部确定性目标覆盖随机采样。该验收段特意比训练随机2～4秒长，使慢斜率也有稳定测量时间。

500Hz采集实际命令、隐藏目标、真实机体系vx、支撑力、机身接触、姿态、角速度和位置。每段全部完成且门控有效，斜率完成后0.5秒起统计，至少0.5秒稳定样本，MAE≤0.30m/s；全过程总倾角acos(-gravity_z)≤25°，机身接触≤1N且无倒置。未起立、失稳、提前结束或样本不足都不能算通过。

急走报告真实速度进入目标±0.30m/s并连续0.5秒的确认时间与最大俯仰；急停额外报告平面速度≤0.05m/s连续0.5秒的确认时间、从目标归零请求到确认的路径长度，以及触地/倒置。未停下标失败并报告已观察路径，终止后复位位置不计入距离；未给时间/距离上限，当前只记录，不编造门槛。可用`--acceleration .5/1/2`分别验收。

零速组单独沿用v3.1末连续1秒承重/角度/角速度/接触判据，并要求曾站起，慢移单列不扣分；不与移动组25°/速度指标混为一个成功率。脚本支持2999、3999及新v6权重，仅冻结推理，不学习；`--selfcheck`只核对统计边界，不代表行为通过。
