## 接口定义

|---|---|
| 当前帧观测 | 0～2为机体系角速度，3～5为重力方向，6～8为前进速度/偏航速度/高度命令，9～12为相对标称值的四髋角，13～18为六轴速度，19～24为上一次动作；缩放沿用复旦行走配置 |
| 历史 | 五帧，共125维，沿用当前复旦history/reset约定 |
| Critic | 环境141维，加3维编码器估速后输入144维 |
| 动作顺序 | lf0、lf00、lfwheel、rf0、rf00、rfwheel |
| 动作含义 | 四腿位置目标相对标称角偏移，缩放0.5 rad；轮速度目标缩放10 rad/s，目标上限58.4 rad/s |
| 增益与力矩 | 行走初始P/D为30/2；轮速度P/D为0.1/0；腿/轮名义限矩40/3.9 N·m，训练仍采用配置中的强度随机化 |

| 限位 | 四髋连续转动，后支链六被动轴连续转动；膝左[0.033,0.96]、右[−0.96,−0.033] rad |
