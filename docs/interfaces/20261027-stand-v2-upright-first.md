## 奖励与课程

本版主动偏离Isaac原配方，不再声称19项全部逐值等价。保留15项公式，修改高度、姿态、竖直速度和横滚/俯仰角速度4项，删除额外的getup_inverted，奖励总数为19。

倾角`theta=acos(clamp(-projected_gravity_z,-1,1))`。高度门控在≤15°时为1，在15～40°按角度线性下降，到40°为0。高度奖励为：

```text
exp(-(height-command_height)^2/d) * upright_gate * (1-0.8*clamp(base_force/5,0,1))
```

宽奖励`d=0.01 m²`（误差0.10m时exp(-1)），精确奖励`d=0.0025 m²`（误差0.05m时exp(-1)）；d是指数分母，不称作高斯标准差。

姿态原始罚项改为`1+clamp(projected_gravity_z,-1,1)`，权重-1。直立0、侧倒1、倒置2；低位也生效，取消旧高度进度乘数和解锁后乘10。该项不做原加权±1限幅，最强姿态扣分为-2/秒、100Hz时-0.02/拍；其他奖励继续单项加权限幅±1后统一乘dt。它不是对姿态角“处处有非零导数”的保证，也不保证策略不会倒置。

`lin_vel_z`与`ang_vel_xy`在首次站稳前使用原强度10%，有效权重为-0.1/-0.02；首次站稳后恢复原-1/-0.2，即使之后失稳也保持该强度。各项原有饱和规则保留。其他15项的公式与原has_stood门控保留。

成功定义改为：倾角≤15°、机身高度≥0.20m、机身接触力模长≤0.1N、每轮向上支撑≥max(当前重量10%,5N)、双轮合计≥当前重量80%，连续50策略拍即0.5秒。站稳计时按整数拍换算秒，避免浮点累加漏掉第50拍。`has_stood`只记录本回合曾成功，失稳不清除，到复位清除；`standing_time`表示当前连续满足上述条件的时间，任一失败立即清零。

全局解锁仍为4096个完成回合窗口内成功率≥30%，初始目标0.30m，解锁后0.22m；成功高度两阶段均为0.20m。只有全局已解锁且该环境当前连续站稳≥0.5秒时才启用窄高度奖励；否则始终用宽奖励。全局解锁后每次复位仍从宽奖励开始，再失稳时立即回宽奖励。本版没有额外1秒插值或新阶段变量。
