## 复位与PD中心

`reset_geometry.py::ResetGeometry.solve`固定六个电机到**现有**PD默认中心（含启动时每环境采样一次的±.03偏置），只解被动膝/后连杆和弹簧几何。默认偏置不在每次复位重采样；每个环境的合法解缓存复用。共享XML、PD增益/目标尺度/限幅/弹簧和随机化范围未改；若某个实际采样中心求不出合法闭链、越限或碰撞网格穿地，初始化明确失败，不裁小偏置、不重抽成功样本。

以最低轮碰撞网格加2mm间隙决定根高度，并检查其他碰撞网格不低于轮底。名义高度约.339016m；129组检查覆盖名义、六维全部64个±.03角点、64个固定种子随机偏置，高度约.33035～.34764m。**这是初态几何，不把目标命令.22～.30m扩大到这个区间。**

实际写入float32后重新做静态运动学检查：最大闭合误差2.37e−9m，最小地面网格间隙约.001999985m，无关节限位违规，电机q与PD中心逐槽相等，零动作位置P项为0。气弹簧力、重力和随机根速度仍存在，不能把“P项为0”写成总力矩为0或动态站稳。

## 启动与正常复位

构造环境不额外推进热步。默认训练调用`initialize_rollout → FudanEnv.reset → reset_idx(all) → step(zeros)`，只计划一次10ms零动作策略步（本机5×2ms）；返回该步观测后才随机首轮局部回合计数0～1999，并同步底层回合计数。全局total_steps/common_step_counter保留热步后的1，不被随机相位覆盖。空重采样集合不产生新的命令样本。

正常回合终止只调用`reset_idx(ids)`，不额外推进任何环境；局部复位更新各自状态/历史/动作/参数引用，其他环境已计算的传感派生量、历史和进度保持。全局课程时钟仍按total_steps的2000拍边界判断；超时仍严格>2000，命令仍每500拍重采样。

按本次明确选择，保留本机现有的**复位后刷新真实状态、清上次动作**，不复制原参考正常reset跨回合旧action/gyro/gravity缓存。这是明确记录的本机差异，不能称原参考潜在缓存问题已被逐位复现。

历史先填5帧无噪声proprio，再在该次观测计算时追加一次带噪帧，得到**4净＋1噪**。history保存加噪后、clip之前的帧；Actor current和Critic单独clip±100。Critic仍在Actor加噪前构造，噪声幅度/字段不变。下一步正常历史只推进一次。
