# 串联腿 mjlab 随机初态接口 r3

历史记录：当前模式接口已升级 [r4](chuanliantui-mjlab-huananhu-v14-flat-standup-r4.md)，本页保留r3模型对应的定义。

日期2026-10-09，分支 `26_wheelleg`，基础提交 `58947e8` 加未提交修改。用户要求初始位姿随机化并参考华南虎。

## 变化范围

r3恢复SCUT V14 flat v0普通／地面混合初态，保留 [r2实体弹簧](chuanliantui-mjlab-huananhu-v14-flat-standup-r2.md)、35／78／6维、实体电机顺序、50 Hz、Kp10／Kd1和普通PPO。静站目标0.22 m、速度命令零、启动电机0.2 s零力矩覆盖保持当前任务定义，没有移植源行走命令覆盖。

| 初态字段 | 定义 |
|---|---|
| 模式概率 | 每机器人普通50%、地面50% |
| 地面腿姿 | 左右独立采样；各60%正摆角、40%负摆角 |
| 腿长 | 源普通0.13～0.32 m、地面0.14～0.36 m按归一化伸展映射到本机器人约0.171637～0.336744 m |
| 普通摆角 | 源−π/2～0.75π；姿态表按本机构装配分支／限位／碰撞过滤 |
| 根姿态 | 普通roll/pitch±0.15、yaw±3.14 rad；地面水平且yaw=0，按源模式定义 |
| 根高度 | 普通至少0.35 m，几何保守界必要时抬高；地面0.25 m |
| 轮角／关节速度 | 轮角±2π；四腿电机速度±π/2 rad/s；轮速±50 rad/s；根和被动关节速度零 |
| 闭合初始化 | 从1024行／模式的CAD姿态表独立取左右腿，连同全部被动关节、弹簧转动／伸缩坐标复位 |

普通根抬高是机器人碰撞几何适配，避免沿用源高度穿地；姿态表不是源连续采样的精确分布。主动随机速度／被动零速度按源约定，不额外投影约束速度。10 mm预压、0～150 N弹簧曲线与参考质量仍非实测标定。

## 资产与兼容性

`ct_mjlab/reset.py`只在GPU采样；`reset_poses.npz`及同名JSON由离线脚本 `scripts/agent/import_chuanliantui_mjlab_reset_bank.py` 移植用户指定本机工程的CAD姿态表。逐关节按qpos0差值转换电机坐标，核对同一CAD机体位置／旋转／轴、关节限位、全部闭合关系和参考端点。运行时没有外部仓路径依赖。

manifest新增reset配置、姿态表和采样器SHA，接口ID升级r3。此前r2短训 `model_28.pt`保留但不自动resume到r3；本次新建训练run从随机权重开始。确定性CPU／默认play初态仍为原0.15 m后摆，训练和 `play --random-reset`使用随机初态分布。

验证和可视训练记录见 [r3检查](../diagnostics/20261009-mjlab-random-reset.md)。新策略尚未正式行为验收、导出或H7适配。
