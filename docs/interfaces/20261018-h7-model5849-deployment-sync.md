## 训练侧重点复查

- `rc.len`是公共腿长目标，当前直接作为RL高度命令使用；低于0.27m的行程被截住，现有K表又将公共目标上限限制为约0.31m，因此并非完整覆盖0.27～0.34m。
- 仿真使用机身接触力与绝对高度；实机用髋轮投影间距≤0.20m作为低高度替代。数值相同不代表物理定义相同，尤其悬空或机身倾斜时。请核对该替代对recover进入、退出及超时的影响。
- 核对q_nominal/q_reference、反馈及action重排、ground_start锁存、policy_active、连续倒地计时和实际出力门控。不得因网络维数匹配或编译通过，就认为策略恢复效果已通过。
- 本轮没有改变训练环境、奖励或模型权重，也没有重新训练；旧3023形状可匹配不表示其行为已经在当前部署配置验收，当前配套交付使用5849。
