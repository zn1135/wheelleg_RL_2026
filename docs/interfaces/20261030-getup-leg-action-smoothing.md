## 接口定义与差异

只给四腿动作索引0/1/3/4（lf0/lf00/rf0/rf00）加入递归平滑：`filtered_t=0.8*raw_t+0.2*filtered_(t-1)`，混合的是上一拍已经平滑的值。每10ms策略拍更新一次，5个2ms物理/PD子步间保持。然后进入原延迟队列、默认角+0.5×动作、位置限幅、60/2 PD及±40N·m限矩。滤波不重复应用于每个物理子步，现有随机动作延迟保持。

轮动作索引2/5不平滑，仍为原10×动作轮速目标及原增益/限幅。XML、闭链几何、弹簧、默认关节角、世界/IMU坐标、目标高度、课程、终止和全部奖励（包含已加倍的torques）不改。walk及独立旧stand_v2沿用原动作类。

原始网络动作仍用于上一动作观测及动作变化奖励，25维/五帧125维/训练评分71维不变，索引、单位、缩放和FIFO时机不变。平滑只改变送往PD的四腿动作副本，不修改PPO采样值。滤波有图外跨拍缓存，局部复位只清对应环境；全复位清空全部缓存。起立前0.2秒零力矩等待期间缓存持续清零，第21拍首次执行为新动作的80%。默认姿态本身的接管跳变未另外插值，不承诺因此消除起立猛蹬。
