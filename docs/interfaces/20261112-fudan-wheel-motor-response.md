## 控制链与单位

PD计算 → 原±15%强度随机化 → 原名义请求±3.9Nm限幅 → 既有通用电机响应 → **独立轮端延迟/一阶响应/输出增益** → 原轮速衰减 → 额外轮轴输出上限 → MuJoCo ctrl → XML固定增益G。

独立层不改PD参数和PD请求记录。输出上限以ctrl×XML固定G对应的轮轴Nm表示，写回时除以G；G只由原后端施加一次。0.45候选在PD限幅之后缩放，因此饱和时提交名义ctrl约1.755，而降低轮P或限幅前强度缩放仍可能提交3.9。1.755不是已经测得的真实轮轴力矩；两侧G约1.8473/1.8556。

| sim配置 | 默认 | 含义 |
|---|---:|---|
| wheel_motor_gain | 1 | 限幅后的输出倍率；本轮试验0.45/0.75/1 |
| wheel_motor_delay_ms | 0 | 仅轮端命令额外数据龄，按2ms物理拍量化 |
| wheel_motor_time_constant_ms | 0 | 一阶响应时间常数，0逐值旁路 |
| wheel_motor_torque_limit_nm | None | 可选左右轮轴额外输出上限，None不增加限幅 |

**默认不采用未经标定的0.45、延迟或新上限。** gain1/延迟0/时间常数0/无额外限幅时，直接保持旧控制提交路径；GPU实际读回与原P0.1路径逐值一致。响应层有各环境独立状态，局部复位只清对应环境，保留其他环境状态与参数。

训练/普通GPU配置均读到恢复后的轮P0.1及默认中性响应。旧14179仍是轮P0.045训练的历史候选，其快照/权重/交付包不改写；复现实验必须显式采用当时配置，不将旧分数当作新物理分数。历史参数探针明确固定轮P0.1，再按profile使用限幅前强度或新输出增益。
