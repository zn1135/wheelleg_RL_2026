# Isaac起立奖励v3：凸速度成本

## 为什么修改

轮std0.02试验中，401轮末5s均速0.015480m/s、速度std0.00296，601轮均速0.016770、std0.01329；原指数速度得分却由0.551753升为0.591275。在这些轨迹上，更大的速度波动提高了得分。它足以证明该速度项与“更小均速/更少波动”的局部排序有冲突，不证明全部PPO退步只由它造成。

原最多1000轮试验已SIGINT结束，实际日志新增539轮，训练计数739；最后保存701轮模型，38轮日志未保存。完整证据在artifacts/ppo-wheel020-phase1200-20261026-v1；未完成1000轮，也未替换保留的200轮候选。

## 最终公式

新增独立选项`--bc-finetune isaac-standup-v3`。仍沿用原先连续站稳0.5s后的has_stood门控；令e=(vx-command_vx)^2+vy^2，两个加权速度奖励合计为：

`has_stood * [1 - 10*(sqrt(e+1e-12)-1e-6) - 5*e]`

原主项权重1、增强项权重0.2保持：主项原始值1-10*平滑速度，增强项原始值-e/0.04。两项不再按±1限幅，否则会重新引入高速度下的非凸成本。其余17项仍保留原加权限幅，SMP不改。固定站稳门控时得分是速度的凹函数，因而相同平均速度下增加波动不能提高得分。

开发初版曾加“首次进入0.1m/s低速区”的额外历史开关，检查时发现该新状态不在观测内，最终取消，未用它训练。`ppo-convex-reward-check-20261026-v1`是该已放弃原型的检查；当前采用v2及后续的原门控版本，不混用其未训练检查点。

actor39/critic82、轮角参考、动作6、初态分布、2ms物理/100Hz策略、0.2s等待、2/4ms延迟、XML/标定/H7保持。没有给策略或价值网络添加新的历史状态。
