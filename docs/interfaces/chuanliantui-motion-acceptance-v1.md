# 串联腿统一运动验收标准 v1

2026-11-02用户确认所有行走策略（含复旦）采用本表四项门槛，并统一GPU流程和报告，见[统一GPU验收](20261102-unified-gpu-acceptance.md)。起立仍单列；旧复旦宽门槛只作历史诊断。

2026-11-01 用户确认以下四项为统一运动标准。标准已确定；multimode、stand_v2 tracking／速度／转向及SuperMimic的运动判定已接入共用实现。旧脚本的历史通过结论不能直接标为本标准通过。

## 范围

针对站立初态下的前进、后退、转向和停车；起立暂不纳入本次统一。相同运动能力采用同一判据，不随训练算法或模型版本变化。仿真、CPU回放和真机分别记录测量条件及结果，不互相替代通过结论。

## 已确认判据

| 项目 | 计算与门槛 | 统计阶段 |
|---|---|---|
| 前后速度跟踪 | 实测机身前向速度与目标速度之差的绝对值取平均，≤0.10 m/s | 稳定运动阶段 |
| 转向速度跟踪 | 实测机身偏航角速度与目标角速度之差的绝对值取平均，≤0.10 rad/s | 稳定运动阶段 |
| 停车 | 世界坐标系水平速度 `sqrt(vx²+vy²)` 的最大值≤0.05 m/s | 停车稳定阶段，前向与转向请求均为零 |
| 稳定俯仰 | 俯仰角绝对值的最大值≤5° | 稳定巡航及停车阶段 |

门槛包含等号。平均误差使用绝对值，正负偏差不能抵消；停车和俯仰使用整个对应阶段的峰值，不能以均值替代。各样本、各阶段分别计算，再汇总成功比例，不能让其他样本的低误差抵消失败样本。

## 测量完整性与比较

测量须完整且无数值异常。提前终止的样本保留在原分母中，不通过筛选幸存样本抬高成功率；输入缺失或阶段不完整不能判为通过。目标请求、实际送入策略的指令、实际运动分别记录，避免把指令未送达当作模型已完成目标。

模型对比使用相同初态、命令、物理条件和测量时段；保留原成功样本任一失效即判退化的规则。双轮承重等平衡指标继续按[双轮平衡标准](chuanliantui-wheel-balance-acceptance-v2.md)单列，本表不重新定义该标准。

## 尚未确定的完整运动协议

本次确认的是四项数值门槛。刹停允许用时、加减速允许倾斜幅度与持续时间、稳定统计窗口、完整速度／转向覆盖范围及整组通过比例尚未统一。不得因本表四项通过就宣称完整运动能力验收通过。

已有记录可以按明确写出的原测量窗口重新计算这四项，结果须注明窗口及覆盖范围；不能根据结果事后挑选有利时段。缺少逐步轨迹的旧报告不能由汇总数推算新标准结论。

## 实现迁移

统一实现见`scripts/agent/motion/assess.py`，共用指标计算、阈值和逐样本判定。原`check_multimode_tracking`合并为该模块的`--selfcheck`，原`check_stand_v2_tracking`合并为`--audit-tracking`；不保留旧路径包装。历史源码与原报告保留原义；新标准复算结果写入新目录，并记录原数据来源。

旧multimode的0.30 m/s、0.30 rad/s门槛，以及SuperMimic中未确认的0.05 m/s平均误差／0.10 m/s百分位建议，不作为本标准的跟踪门槛。高度、航向保持、腿部摆动可继续单列测量，但不新增为本次已确认的四项门槛。
