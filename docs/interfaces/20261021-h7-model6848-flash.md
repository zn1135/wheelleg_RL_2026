## 可复现构建与写板边界

从本独立worktree根目录编译：

```bash
DOTNET_ROOT=/home/zn/.local/share/dotnet \
  /home/zn/.vscode/extensions/cl.eide-3.27.2/res/tools/linux/unify_builder/unify_builder \
  -p artifacts/h7-model6848-flash-20261021/builder.params --rebuild
```

写板前必须按本次调用的烧录技能提醒并取得**本次**断动力确认；调用技能或上次确认不能替代。取得确认后才可使用本次成功构建HEX，OpenOCD仅program/verify/reset，不做全片擦除、保护位调整或动力试验。下载器识别不等于目标连通；完整日志中的Programming Finished、Verified OK、Resetting Target才是写入校验复位成功证据。

```bash

  -f target/stm32h7x.cfg -c 'adapter speed 1000' \
  -c 'program {artifacts/h7-model6848-flash-20261021/build/CtrBoard-H7_ALL.hex} verify reset exit'
```
