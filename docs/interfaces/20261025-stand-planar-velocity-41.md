# 独立稳站：41维策略输入与分阶段随机化

本页是r25/r26历史接口。用户随后要求恢复第15、16维轮角占位、不使用Actor平面速度，当前定义见[39维轮角占位接口](20261025-stand-wheel-placeholders-39.md)；旧模型和本页记录不改写为新接口。

2026-10-25，用户明确选择同时减小噪声、调整随机化并加入机体平面速度，允许迁移旧模型。仅适用于 `chuanliantui_stand`；原 `chuanliantui` 保持39/82/6。训练仓分支 `26_wheelleg`，基准提交 `2893b88ae99b61c3f9d06f06cb54b8d3ea94c4c3`；实际运行源码由每批配方快照和校验值确定。

噪声与随机化强度按批次评估逐步恢复，不在运行中修改配方。r26将训练噪声从0.2提高到0.4，物理及电机随机化仍为0.25，新增速度噪声仍为±0.01m/s；正式评估继续原完整噪声和随机化。扰动课程、恢复奖励豁免、目标0.27米/零速度及速度v2的20秒、500Hz原始采样判据不变。

r26仅在近站复位的间隙点积中保留历史TF32算术，随后恢复原网络IEEE设置，消除历史初高一个float32位的差异；不改复位分布、姿态、XML或控制时序。原默认IEEE复位报告、显式历史算术复放报告与全部失败均保留。

## 兼容与迁移

旧39维稳站模型必须经`scripts/agent/migrate_chuanliantui_stand_velocity.py`显式迁移。Actor首层原39列逐值保留，新2列补零；对应Adam一阶、二阶矩补零，其余Actor、动作采样标准差、Critic及优化器历史保留，不清空训练轮数。新通道在迁移时尚未学习，其后通过续训获得作用。禁止覆盖旧模型与配方。

权威实现：`chuanliantui_stand/observations.py`、`randomization.py`、`action.py`、`runner.py`及迁移脚本。有限验证入口为`check_chuanliantui_stand.py`和`check_chuanliantui_stand_velocity.py`，有限检查不替代行为验收。
