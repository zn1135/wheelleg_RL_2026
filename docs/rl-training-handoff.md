## 3. 当前训练方案

- 采用华南虎 V14 flat v0 普通 PPO 的网络、奖励和随机化方案；参考版本、参数及明确的后端差别见 [迁移说明](mjlab-chuanliantui.md)。机器人替换为本项目串联腿 CAD 闭链机构。
- 当前任务是后摆落地起立／静站：初始根高度 0.15 m，目标高度 0.22 m，前向、侧向和偏航速度命令均为零。
- 不使用虚拟关节控制。四个实体腿电机控制位置，两个轮电机控制速度；被动关节由闭链物理解算。
- 气弹簧为每侧 150 N 恒定伸张力，从 CAD 端点构造原生 spatial tendon，随姿态计算轴向力和广义力。它不占动作通道，也不作为腿电机前馈补偿；真实弹簧力曲线仍需与实物核对。
- actor 与 critic 均为 `256 → 128 → 64`、ELU；普通 PPO，无旧 encoder。critic 的 78 维特权观测只用于训练。

## 4. H7 必须对齐的策略接口

接口标识：`chuanliantui-mjlab-huananhu-v14-flat-standup-r1`。

**ONNX：float32 `observation[1,35] → action[1,6]`，opset 13，固定 batch=1。** 图内只有 actor；观测处理、动作缩放、PD 和控制时序在图外。

机体系：+x 前进、+y 左、+z 上。六维位置、速度和动作统一按以下实体顺序：

```text
[lf0, lf00, rf0, rf00, lfwheel, rfwheel]
```

CAD 左右名称已更正：`lf` 是实际左侧，`rf` 是实际右侧。旧文档和模型中的名称须按历史版本解释。电机槽位、编码器零点、转向符号和 IMU 变换需要按实物核对，不能仅凭名称推断。

### Actor 35 维字段

索引从 0 开始，范围为左闭右开；角度 rad、速度 rad/s。

| 索引 | 字段 | 推理时处理 |
|---|---|---|
| `0:3` | vx、vy、wz 命令 | 当前任务全零 |
| `3:4` | 高度命令 | `0.22 × 5 = 1.1` |
| `4:7` | 机体系角速度 | 限幅 ±100，乘 0.5 |
| `7:10` | 机体系投影重力 | 单位重力方向，限幅 ±100 |
| `10:16` | 六实体关节相对名义角 | 轮位置槽置零，限幅 ±100 |
| `16:22` | 六实体关节速度 | 限幅 ±200，乘 0.1 |
| `22:28` | 上一拍策略请求动作 | 控制缩放前的动作，限幅 ±100 |
| `28:35` | ctrl mode | 固定 `[1,0,0,0,0,0,0]` |

名义关节角约为 `[0.06, -0.059270409, -0.06, 0.059270409, 0, 0]`；准确值以 `poses.json` 为准。这是模型参考姿态，不是可直接写入固件的电机零点。回放不添加训练用随机观测噪声。

### 动作和时序

| 项目 | 当前训练／回放定义 |
|---|---|
| 策略周期 | 20 ms，即 50 Hz |
| 物理／软件 PD 周期 | 5 ms，即 200 Hz；每策略拍 4 个子步 |
| 四腿目标角 | `nominal + 0.5 × action`，目标限幅 ±π |
| 四腿 PD／限矩 | Kp=10、Kd=1，40 N·m／电机 |
| 两轮目标速度 | `10 × action`，目标限幅 ±20 rad/s |
| 两轮速度增益／限矩 | Kv=0.1，3.9 N·m／电机 |
| 启动 | 前 0.2 s 电机零力矩，气弹簧仍施力 |
| 训练延迟 | 状态延迟 1／2／3 个物理子步，动作延迟 1／2 个物理子步；reset 清历史 |

动作本身没有统一 ±1 限幅；网络输出不是电机力矩。训练中的随机延迟和参数扰动是鲁棒性建模，板端要记录并核对实际延迟与控制时序；不能从上述数值直接推断已有硬件链路等价。
