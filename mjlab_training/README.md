# Chuanliantui on mjlab

Independent Python 3.12 / mjlab runtime. SCUT V14 flat v0 ordinary PPO recipe, physical closed-chain joints, CAD gas spring tendons.

See [migration, interface and commands](../docs/mjlab-chuanliantui.md). Run commands from the repository root with `scripts/mjlab.sh`. This machine reuses its existing mjlab installation through a local environment; `uv sync --project mjlab_training --locked --python 3.12` is for a fresh installation.

No training has been started as part of the migration.
