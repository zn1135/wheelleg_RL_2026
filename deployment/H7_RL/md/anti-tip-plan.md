### 本次实际计算与接入

```text
L_guard = max(L_left, L_right, 两腿已经过本机机械范围裁剪的目标)
H_reference = L_guard + 原turn_comp.height_offset
B = 9.81 * 原turn_comp.track * budget_fraction / (2*H_reference)
speed_guard = max(|实际融合速度|, |速度请求|)
limit_raw = min(原rc.yaw_max, B/max(speed_guard,0.05))
limit = 首拍limit_raw；以后min(limit_raw, 前拍limit+release_rate*dt)
ratio = (K_左轮_phi-K_右轮_phi)/(K_左轮_dphi-K_右轮_dphi)
equivalent_raw = yaw_rate_hold启用的转速参考 + ratio*yaw_hold启用的环绕航向误差
equivalent = clamp(equivalent_raw, -limit, limit)
scale = 超限时limit/|equivalent_raw|，否则1
```

machine_config.c/.h在lqr.motion_guard保存试用策略：大机enabled引用上述宏、budget_fraction=0.375（沿用此前0.75×0.5）、release_rate=3rad/s²；小机enabled=0。0.375与3为可调整的初始试用策略，不是物理标定或安全极限。

lqr_balance.c/.h：LQR_Control_Update新增guard_permit。当前K生成后调用Motion_Guard_Update，然后仅将偏航角误差和偏航角速度参考部分乘scale；角速度测量负反馈不乘scale，其他八列及原yaw开关保持，原target/yaw_target不回写。输入角速环关闭时不计该参考，角环关闭时不计航向误差。不能把等效参考上限当作实际转速上限；其余状态列、执行器饱和仍会影响转向。

control_compute.c：只有Compute_LQR内有效NORMAL传许可；LQR_Idle和拍末非LQR/非NORMAL/输出候选无效/后处理抑制时清历史，不再每拍无条件复位。Motion_Guard_Update返回新计算无效（如不可用增益比）时沿原无效候选路径拒绝本拍，不生成伪造的安全值。AIR/自起/RL、原向心力腿力补偿、最终许可及电机输出口不改。

7. 限值恢复采用有界连续释放，预算收紧时优先保证约束；阈值附近无抖动。此项只处理保护释放，不引入通用遥控斜坡。

成功判据：回放中不超有效目标预算；正常工况不干预；所有航向目标路径受覆盖；退出/重新投入无残留；制动方向和停车距离无意外变化。之后才进入低速实机验证。

## 第三阶段：实机验收（作者执行）

先静立/低速核对左右估力可信度，再按低/中/高腿长、左右转、不同载荷逐步扩大工况。
每个工况记录无干预/有干预对照，不故意试到翻倒。观察最小内侧轮载、roll峰值与角速度、实际v*w、干预持续时间、轮矩限幅和停车距离。
软件编译、模型计算与CSV回放不等于板端防翻有效。
