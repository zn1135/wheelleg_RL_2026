# 自动磕台阶：当前接入与实测入口

## 当前大机AUTO试用（2026-11-03，覆盖下方观察版本）

作者明确授权取消轮速限制，改为两腿实际腿长均>=0.27m；仅此下限，不另设检测腿长上限。speed_max、length_max及检测输入wheel_velocity已删除，VOFA14～16仍只读记录轮速供分析。NORMAL/投入/反馈许可、转向请求0.3rad/s、实测偏航开窗1.2rad/s、冲击80rad/s²、腿角偏差0.1rad、350ms窗口与20ms确认保持。当前大机mode=AUTO(2)，检测confirmed=1、动作confirmed=1；这是作者允许首轮实机动作，不代表越阶已验收。小机OFF。

目标由作者选择参考LHX：左右摆腿终点均1.3rad，摆腿期间保持触发时各腿实际长度，收腿终点均0.17m。只继承动作目标，实机符号/零点/几何/MIT量程均未改。识别成功当拍进入stair_process独立路径，双轮请求为0；SWING→RETRACT→RECHECK，失败走独立WAIT，退出LQR投入/故障仍停止。动作期间不因摇杆回中改目标或取消，姿态检测暂停；最终按新姿态重新交接原三态。

作者随后要求PD/速度限幅/斜坡rate复用自起参数。本次取消台阶单独的显式速度阻尼增益及rate配置，通过任务Compute_Stair读取同一参数源，组装stair_control_param_t传给纯动作模块：长度PID来自machine->lqr.pd.leg_len；串级摆角位置/速度环Kp/Kd及角速度限幅来自fallen_process_param；长度/角度rate及支撑渐入也取该源。当前快照：位置45/15、速度5/5、角速度上限8rad/s、角度目标rate4rad/s、长度rate0.7m/s。具体参数始终以源码为准。

与自起使用同一个pid_calc误差差分口径、PID_History_Set及Ramp_Target_Update，不把旧Kd当作直接速度阻尼。长度/摆角PID、长度斜坡、连续角、支撑渐入和超时历史仍归stair_process独立实例，不读写Fallen_Process上下文。模型支撑幅值/腿角权重同源，SWING渐入支撑，RETRACT释放基础摆矩并收腿。自起实现本身未修改。目标、到位容差及台阶独立超时/卡滞配置仍在machine.stair.process。

### 本轮烧录后的采集

新版会真实出动作，不能按观察版预期阶段始终为0。5号应为2；8号确认位应同时具备bit6与bit12；6号应由0→1摆腿→2收腿→4重判→0，失败为3等待再重判。46号是识别次数，不代表通过次数；6/7/8/10/11联合区分未触发、动作进行、完成与超时/卡滞。26/27是长度目标，28/29是角目标，18/19与24/25为反馈，36～45为最终请求/反馈。保留8号bit13～15最近清窗原因。全部48列CSV及一次实际碰阶时间/结果用于判断是否进入处理、是否按目标推进、最终能否越过。

下面v1～v3的OBSERVE、confirmed=0、显式PD和旧门槛说明均为历史，不再代表当前试用固件。未烧录或做实机动作验收，不能把软件验证称为已能上台阶。

## 当前观察判据v3：入口与保持分开（2026-11-03）

当前长度范围与轮速/实测偏航范围均只限制新冲击开窗。已经捕获的窗口不再因腿长短暂越过检测边界而直接清空，继续在原350ms期限内对腿姿连续确认20ms。松杆/反向、转向请求超限、失去NORMAL/基础许可、无效新计算、取消武装及超时仍清窗；不新增无限保持的卡阶状态。原机械工作区、动作轨迹、AIR与自起保持，大机OBSERVE及两组confirmed=0保持。

清窗通过Stair_Detection_Clear统一处理，只有真实候选结束才锁存clear_reason，空闲拍不会覆盖；直到下一次候选结束或整体Reset才更新。新增诊断仍使用原48路，在8号bit13～15编码最近一次结束原因，与bit8～10处理结果、bit12动作参数确认位不重叠。解析为`(整数ch8 >> 13) & 7`：

| 码 | 最近一次候选结束原因 |
| --- | --- |
| 0 | 尚无结束记录/整体Reset |
| 1 | 向前请求不足、回中或反向 |
| 2 | 转向请求超限 |
| 3 | NORMAL或基础输入/出力许可失效 |
| 4 | 冲击窗口超时 |
| 5 | 姿态确认成功并发布事件 |
| 6 | 取消武装 |
| 7 | 新计算结果无效 |

这是上一次结束原因，不是本拍是否仍有候选；本拍窗口仍看8号bit4，确认时间看9，累计事件看46。长度波动不再是已开窗口的结束原因，仍可阻止新开窗。输出几何有效性、力映射和最终许可没有放宽。台阶接管暂停观测时也保留原因编码。

v3验证：实际IDE builder.params两源各一次，大机据该清单Rebuild链接通过，小机GCC及相关源大小机AC5编译通过；原核心970/路由169及新增保持/原因43项C断言通过，100拍OBSERVE原控制输出轨迹一致。两份CSV已记录特征的保守回放，修改前后分别均为1次、2次事件；第二份回放时刻与实际计数部分不一致，受导出空档及1kHz中间反馈缺失影响，不能宣称漏检率已改善或据此确定原清窗根因。未烧录/实机验证。

下一次仅验证一次接近→卡住→撤开，并保留几秒正常起停/低速转弯对照；导出全部48列，我方从8号高位直接判断结束分支，无需操作者现场解码。仍不开放AUTO，也不因持续顶住而自动反复执行动作。

## 当前观察判据v2（2026-11-03）

根据stair测试.csv修订：不再要求大角加速度与大腿角同拍持续成立，而是角加速度上升沿开启350ms窗口，窗口内双腿角偏差连续20ms到位才发布观察事件；后续尖峰不续期。回中、后退、转向请求超范围或失去NORMAL许可均清候选。轮速/实测偏航仅限制开窗，避免碰撞后的轮速/偏航突变立即抹掉已捕获窗口。

试用检测参数：angle_min=0.10rad、acceleration_min=80rad/s²；轮速开窗上限0.6→1.5m/s；转向请求仍0.3rad/s，实测偏航开窗上限独立设为1.2rad/s；检测腿长范围0.14～0.33→0.135～0.345m。后者是识别容差，机械工作区和控制目标没有放大。均为本次记录的观察试用值，不表示已验证识别率。

大机仍OBSERVE，两组confirmed仍0。v2将“计算试用事件”与“允许AUTO接管”分开：OBSERVE可以武装、开窗和累计46号通道；AUTO必须检测confirmed及动作confirmed均为1才能接管。没有启用自动摆腿，动作路径/增益仍待实测。旧文中“confirmed=0不武装”及同拍组合说明由本节覆盖。

48通道编号保持，8号bit4改为冲击窗口有效，bit0表示允许开窗；9号为窗口内双腿姿态连续确认时间。其余位/单位保持。原CSV中的全零事件不是漏执行，而是v1尚未允许试用候选。

实际C确认逻辑消费已记录角加速度/腿角做离线回放，大于10ms的导出空档丢弃窗口，不插值成1kHz数据；29107行发布1次事件，124.955s（相对CSV起点），0～110s对照段无事件。该结果不是实际固件逐拍复现，不等于识别出全部碰撞；松杆/后退及缺测片段不能强行算成必须触发。

## 当前交付边界

新增模块统一命名stair，检测为`stair_detection.c/inc/stair_detection.h`，动作为`stair_process.c/inc/stair_process.h`。自起的Fallen_Process阶段、参数、PID、重试预算未迁入台阶模块。

大机`machine->stair.mode=STAIR_MODE_OBSERVE`，小机OFF。检测与动作参数分别有`confirmed`：它是本机实测确认后的功能许可，不是实时反馈valid。当前两者均0，检测仍记录角加速度，但不武装、不产生触发，不接管输出。待确认的角度/角加速度门槛，以及动作角度、腿长、支撑、速率、PD增益和卡滞进度均没有用参考机/自起数值填充。

配置唯一来源是`machine_config.c/.h`的`stair.detection/process`。已有请求/速度/转向范围、滤波和期限是观察/软件试用初值，不表示本机通过包线；数值以源码为准。首轮CSV确认检测参数后只置`detection.confirmed=1`，仍保持OBSERVE验证误触发；路径、控制参数和避碰确认后才置`process.confirmed=1`并改AUTO。仅切AUTO而未确认参数不能出动作。小机调度额外禁止自动入口，不能因拷贝配置开启。

## 检测与动作

检测输入由执行拍快照提供，不读取遥控原始通道。必须已投入LQR、基础许可和四髋使能正常，本拍公共判断有效NORMAL且普通平衡运行，公共后处理未抑制；随后检查向前请求、双腿长度、轮速估计及请求/实测偏航范围。

候选为双腿几何角相对站立参考的绝对偏差均达到门槛，并且至少一侧滤波角加速度绝对值达到门槛，连续满足配置时间才发布一次事件。角加速度以实际腿角速度按MACHINE_LQR_DT差分，一阶低通系数为dt/(tau+dt)。首次、许可丢失及动作退出后重新播种，不把暂停间隔当成一个周期差分。轮速均值乘轮径是轮速前进估计，不是融合地速；受阻可由请求与该估计对照，当前不作为第三个硬触发门槛。检测的是撞阶特征，不能区分墙和台阶。

普通检测和三态选路先执行；本拍仍为有效NORMAL才允许台阶进入。OBSERVE发布事件但保持原输出；AUTO且两组参数已确认时开始动作。触发后取消武装，持续前进/顶墙不重复触发。重新进入有效NORMAL、候选解除且前进请求回中后才重新武装。

动作只由phase决定输出归属：

| phase | 名称 | 行为 |
| --- | --- | --- |
| 0 | IDLE | 无台阶归属，原控制路径 |
| 1 | SWING | 从实测播种连续几何角/腿长给定，限速摆腿、保持腿长及独立轴向支撑；双轮零请求 |
| 2 | RETRACT | 腿长目标限速收短，基础摆矩归零，物理补偿仍按选定模型叠加；双轮零请求 |
| 3 | WAIT | 失败当拍清候选，用台阶wait_ms独立撤力等待 |
| 4 | RECHECK | 清旧检测历史后按新反馈重新初判；未知期间保持零候选 |

SWING要求双腿实际角、角指令及腿长/指令到位连续确认。RETRACT要求双腿实际/指令长度到位连续确认。角度沿当前几何角连续展开，不另加轴向符号或改变零点。显式PD为`F=Kp*(Lcmd-L)-Kd*dL`、`Tp=Kp*(angle_cmd-angle)-Kd*dangle`，单位见配置声明，不复用旧误差差分PID的Kd。支撑只加在SWING；两阶段经公共Leg_Force_Map_Forward和一次Leg_Compensation_Apply，最终仍由Control_Output_Apply检查并发送。

动作期间摇杆回中、改变速度/转向/腿长不取消或改目标；退出LQR投入、切换策略立即作废，不续跑。暂停AIR、FALLEN判定及AIR/自起处理，公共valid/normal_ready撤销，状态枚举只保留动作来源。普通速度融合、位移及高度观察器不推进，IMU/电机/几何/在线监测继续。最终基础故障许可始终保留；动作中翻倒不会立即由FALLEN中断，只能经动作兜底退出。

阶段/总期限使用HAL毫秒时钟，uint32差值支持回绕。卡滞按各腿独立窗口判断：当前轨迹仍有跟踪误差，且朝终点的实际进度不足才失败；正常到位保持不算卡滞。摆腿阶段检查摆角进度，收腿检查长度进度，其他不到位由阶段期限兜底。

正常完成当拍零候选、下拍开始RECHECK；失败先WAIT再RECHECK。重判时只复位公共AIR、FALLEN观测和三态判断，不借用Control_Postprocess_Request，不修改自起预算。重判有效后交原NORMAL/FLIGHT/FALLEN路径，清落地事件；进入FALLEN仍由原进入事件初始化自起。台阶进入/退出各重建一次普通LQR/速度融合/位移/航向/腿控历史。结果DONE只代表动作完成，不代表已越过台阶。

结果：0 IDLE、1 RUNNING、2 DONE、3 FAILED、4 CANCELLED。退出原因：0无、1动作完成、2退出投入/取消、3基础输入/许可、4映射或补偿/新计算无效、5摆腿超时、6收腿超时、7总超时、8卡滞。结束后保留最后结果/原因供观察，下次开始才更新。

## 当前VOFA：台阶v1固定48通道

旧停车积分布局以#if 0保留，固定人工切换，不按模式自动选帧。编号从0开始。后台临界区复制是软件快照，不是所有设备同一物理采样。

| 通道 | 内容 | 单位 |
| --- | --- | --- |
| 0 | 原IMU/遥控/四髋/双轮在线掩码 | 位 |
| 1 | 原使能/投入/腿有效状态，加bit10台阶输出归属、bit11总力矩开关 | 位 |
| 2 | ctrl_fault | 位 |
| 3 / 4 | 公共三态 / valid；动作期间3为来源，4为0 | 枚举 / 0或1 |
| 5 / 6 / 7 | 台阶模式OFF0/OBSERVE1/AUTO2、phase、退出原因 | 枚举 |
| 8 | 检测标志及结果，定义见下 | 位 |
| 9 / 10 / 11 | 候选连续时间 / 阶段时间 / 动作时间；退出后11冻结 | s |
| 12 / 13 | 前进请求 / 偏航请求 | m/s / rad/s |
| 14 / 15 | 左右轮轴实际角速度 | rad/s |

## 采集和开放AUTO的步骤

1. 编译/烧录当前大机OBSERVE版本，正常投入后录静立、起停、前后行驶、升降腿、低速转弯，分别导出全部48列CSV。
2. 在同一模式下由作者低速接触指定台阶，记录高度、边缘、接近速度、腿长；每次CSV覆盖接触前后过程。此时固件不会自动摆腿。
3. 对照18～23与12～17，确定检测阈值、持续时间和允许范围；填回detection参数并置confirmed=1，保持OBSERVE，对照正常动作误触和撞阶事件是否只计一次。
4. 由作者确认本机连续角路径、避碰、腿长、支撑、控制增益和进度/期限参数后，填process并置confirmed=1，再开放AUTO。不得搬用LHX角度、符号、几何或自起目标。
5. 验证完整动作、左下/右下取消、阶段/总超时、卡滞及故障退出；确认新判断能交回三态，持续顶障碍不反复触发。

构建、宿主C测试和真实越阶分别记录；未完成台架/台阶试验前不标记越阶效果已验证。
