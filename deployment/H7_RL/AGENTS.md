# 内置 H7 部署工程

此目录与训练代码使用同一 Git 仓库，无独立 `.git`。提交、分支、历史训练日志保护遵守仓库根 `AGENTS.md`。

本目录由H7部署负责人维护，RL训练侧由用户本人维护；日常按负责目录分别提交。跨侧接口变更共同核对，目录职责见 [协作指南](../../CONTRIBUTING.md#两人维护分工)。

修改固件前完整读取 [md/AGENTS.md](md/AGENTS.md) 和相关模块文档，尤其是物理极性、零点、轴向和量程约束。导入状态与已知构建配置问题见 [README.md](README.md)。训练与部署的模型接口分别核对；旧板端模型不能直接加载新 mjlab 实体策略。
